# Implementação: AJAX para Formulário de Adicionar ao Carrinho

**Implementação**: Criação de um listener global atrelado ao evento `submit` interceptando os formulários de classe `.egen-prod-card-form`. O script previne o comportamento padrão de redirecionamento, coleta os dados com `FormData` e executa um disparo em background usando a API nativa `fetch()`.

**Motivo**: Melhoria obrigatória de UX (User Experience). O comportamento nativo da loja consistia em postar o formulário tradicionalmente e recarregar ou redirecionar a página para exibir a atualização. A integração orientada a Single Page Interaction (SPI) visa manter o usuário na mesma página de navegação enquanto executa ações de compra.

**Benefício**: Acelera substancialmente o fluxo de compras do usuário. O método intercepta transparentemente qualquer cartão de produto em qualquer view (seja injetado estaticamente na Home, em listagem de categorias ou renderizado dinamicamente) e utiliza o recém-implantado ecossistema de *Toasts* (`window.showNotification`) para reportar o feedback de tela ao usuário sem interromper a sua navegação atual.

## Questão
Como faço para integrar o formulário de "Adicionar ao Carrinho" do cartão do produto (`.egen-prod-card-form`) no `app.js` usando o `fetch` e exibir a notificação de sucesso?

## Resposta Completa do Assistente
Para integrar o seu formulário de carrinho via AJAX, usaremos a mesma técnica de **Delegação de Eventos** que aplicamos no botão de "Lista de Desejos". Isso é fundamental porque, como estamos lidando com um formulário (`<form>`), precisamos interceptar o evento global `submit` e prevenir que a página recarregue (`e.preventDefault()`).

A grande vantagem de usar o `FormData` nativo do JavaScript é que ele varre o seu formulário, coleta o ID do produto e a quantidade automaticamente e monta a requisição perfeita para o `fetch`.
