# 🔄 Diagramas de Atividade (Activity Diagrams)

Este diretório destina-se a armazenar diagramas de atividades em formato PlantUML (`.puml`) ou Mermaid para modelar fluxos e árvores de decisão lógicas complexas no backend.

Para diagramas que detalham a interação síncrona e troca de mensagens entre componentes (ex: controle de transações, concorrência, idempotência e mensageria RabbitMQ), consulte a pasta de diagramas de sequência:
