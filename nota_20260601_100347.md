# [Pré-Implementação do Simulador de Frete na Página do Produto]

**Implementação**
Adicionamos uma nova seção visual de simulação de frete na página de detalhes do produto em [show.html.twig](file:///var/www/html/agsonhos/resources/views/pages/product/show.html.twig):
- Criamos um componente de interface de usuário com estilo premium, integrado com um campo de entrada para o CEP com formatação de máscara automática (`00000-000`).
- Adicionamos regras em JavaScript para validar o CEP informado (exibindo um alerta caso tenha comprimento diferente de 8 números) e revelar um mockup de entrega "Retirar na Loja (Grátis, disponível em até 1 dia útil)".
- O evento do botão "Calcular" também é disparado se a tecla Enter for pressionada dentro do campo.

**Motivo**
Preparar a página de detalhes de produto para receber a integração futura com gateways e APIs de frete (como Correios ou transportadoras), oferecendo uma experiência premium e simulando visualmente as opções de entrega e prazos já na vitrine do produto.

**Benefício**
- Melhora imediata na experiência de navegação do usuário (UX), fornecendo uma resposta interativa sobre formas de envio.
- Estrutura pronta em HTML e JavaScript para a integração direta com endpoints de cálculo de frete backend.

## Questão
Vamos pré-implementar a função "calcular frete" na página de detalhe do produto? Em um primeiro momento, quando o cliente digitar o CEP, aparecerá a opção "Retirar na loja". Será uma especíe de "mockup", preparando essa função para quando nós implementarmos o módulo de cálculo de frete futuramente.
