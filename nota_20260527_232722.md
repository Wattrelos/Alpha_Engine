# [Migração do Menu de Categorias: Atomic Design + CategoryMenuService Standalone]

**Implementação:** Migração completa do `menu.twig` legado para o padrão Atomic Design com novo serviço `CategoryMenuService` standalone (sem OpenCart Registry), integrado ao pipeline Slim → Twig.

**Motivo:** O `CategoryRepository` existente depende do `OpenCart\Registry`, tornando-o inacessível no contexto do Slim (`public_html/index.php`). A solução foi criar um serviço dedicado com PDO direto, aplicando o padrão Batch Load (1 query) + construção da árvore em PHP O(N) — eliminando o problema N+1 queries do menu legado.

**Benefício:** Menu recursivo renderizando 11 categorias raiz com subcategorias reais do banco, usando exatamente as classes CSS do `personalizada.css` já existente (`.ag-menu-container`, `.menu-button-left`, `.dropdown-menu-recursive`, `.submenu`). Zero dependência do OpenCart para a nova rota.

### Fluxo completo

```
GET / → Apache .htaccess → public_html/index.php
  → PDO conecta ao banco (config.php)
  → CategoryMenuService::getCategoryTree() [1 query, O(N) tree-build]
  → AppContainer::get(HomeAction::class) [auto-injeção via Reflection]
  → HomeAction::__invoke() → Twig::render('home.html.twig')
  → home.html.twig extends layouts/base.html.twig
  → base.html.twig includes components/organisms/header.twig
  → home.html.twig includes components/organisms/department-menu.twig
  → department-menu.twig includes molecules/dropdown-recursive.twig
  → dropdown-recursive.twig renderiza a árvore com macro recursiva
  → Resposta HTML 200 OK
```
