# Refatoração: Migração de Estilos Inline para Arquivo CSS Externo (Login)

**Implementação**: O bloco interno de estilos (`<style>`) que continha as definições visuais do container principal da página de login foi removido do arquivo Twig `login.twig` e integrado ao arquivo base `new-stylesheet.css`.

**Motivo**: Manter CSS misturado a marcação HTML viola os princípios de separação de responsabilidades (SoC), aumenta desnecessariamente o payload das respostas de view da aplicação e impede o reaproveitamento e cacheamento adequado pelo navegador cliente.

**Benefício**: Melhoria na performance do tempo de carregamento da página de login e organização centralizada de todas as folhas de estilo, facilitando a manutenção e prevenindo duplicação de regras em um mesmo arquivo.

## Questão
Vamos transferir os estilos (style) de **login.twig** para os arquivos **new-stylesheet.css** ou **personalizada.css** ?

## Resposta Completa do Assistente
Ótima iniciativa. Transferir o CSS inline do template para um arquivo externo é uma excelente prática. Isso melhora a performance (já que o navegador passa a fazer cache do CSS), reduz o peso do HTML (DOM) e mantém a separação de responsabilidades no seu projeto.
