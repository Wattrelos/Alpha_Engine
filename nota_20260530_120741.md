# Roteamento Amigável (Friendly URLs) para Paginação e Filtros de Categoria

## Questão
@[/var/www/html/agsonhos/resources/views/pages/category/show.html.twig] Precisamos implementar as novas rotas de paginação seguindo o nova padrão de rotas URL adotado pelo Alpha Engine que aderiu às boas práticas do mercado.

## Resposta Completa do Assistente
Adequamos a geração de links de paginação, limite e ordenação da página de categorias para utilizarem o novo padrão de rotas amigáveis da **Alpha Engine** (`/{lang}/categoria/{slug}`), substituindo as URLs com parâmetros de consulta legados do OpenCart.

### Alterações Realizadas:

* **CategoryRepository ([CategoryRepository.php](file:///var/www/html/agsonhos/core/Model/Domain/Repositories/CategoryRepository.php#L199-L260))**:
  - Alteramos a montagem do índice `pagination.url` para usar o padrão `/{lang}/categoria/{slug}?page={page}` adicionando as query strings necessárias.
  - Atualizamos a geração de links do array de limites (`limits`) e ordenações (`sorts`) para apontarem para a nova rota amigável mapeada.

Dessa forma, ao trocar de página, alterar o limite de produtos exibidos ou modificar o critério de ordenação, as URLs amigáveis permanecem limpas e otimizadas para SEO.

---

**Implementação**: Substituição de chamadas `$this->url->link('product/category', ...)` no repositório de categorias por concatenação dinâmica estruturada sob a rota amigável `/{lang}/categoria/{slug}`.

**Motivo**: A listagem de categorias e componentes visuais de filtro estavam gerando links apontando para rotas query legadas do OpenCart (`index.php?route=product/category`), quebrando o padrão de SEO e o comportamento do Slim Router.

**Benefício**: Preservação do ecossistema amigável de URLs da Alpha Engine, melhoria no SEO e facilitação do rastreamento de páginas pelos motores de busca.
