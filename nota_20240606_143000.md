# Planejamento: Varredura e Atualização de Classes Legadas no CSS

**Implementação**: Planejamento da varredura para localizar e substituir as antigas classes genéricas `.stucco4` e `.section-title` (para `.egen-stucco4` e `.egen-section-title`) nos arquivos de folha de estilo da aplicação.

**Motivo**: Após a atualização do arquivo de template (`home.html.twig`) injetando o prefixo de escopo `egen-` nos seletores, é necessário sincronizar a folha de estilo base para que as propriedades visuais voltem a ser aplicadas no DOM. Classes no CSS que não correspondem à nova nomenclatura adotada nos componentes Twig resultarão em perda de estilos (layout quebrado).

**Benefício**: Assegura a integridade visual da interface, mantendo a coerência arquitetural de CSS Scoped em todo o ecossistema do front-end e isolando as definições originais contra bibliotecas de terceiros.
