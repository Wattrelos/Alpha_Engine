# [Migração de Estilos Inline para Folha de Estilo Centralizada]

**Implementação**
Movemos todos os atributos de estilo inline (`style=`) do simulador de frete e dos botões da página de detalhes do produto ([show.html.twig](file:///var/www/html/agsonhos/resources/views/pages/product/show.html.twig)) para a folha de estilo global personalizada da aplicação ([new-stylesheet.css](file:///var/www/html/agsonhos/public_html/css/custom/new-stylesheet.css)):
- Criamos regras CSS estruturadas sob a metodologia BEM: `.egen-shipping-simulator`, `.egen-shipping-simulator__title`, `.egen-shipping-simulator__icon`, `.egen-shipping-simulator__form`, `.egen-shipping-simulator__input`, `.egen-shipping-simulator__btn`, `.egen-shipping-simulator__results`, `.egen-shipping-simulator__result-item`, `.egen-shipping-simulator__result-title`, `.egen-shipping-simulator__result-desc` e `.egen-shipping-simulator__result-price`.
- Criamos regras para a linha de compra do produto (`.egen-product-buy`) e para o botão secundário genérico (`.egen-btn-secondary`).

**Motivo**
A presença de estilos inline dificulta a manutenção e a customização futura da interface, violando as boas práticas de desenvolvimento front-end (separação de responsabilidades). Ao mover os estilos para um arquivo `.css` dedicado, garantimos a consistência do design system global da Alpha Engine.

**Benefício**
- Código HTML muito mais limpo, legível e semanticamente correto.
- Facilidade na manutenção: qualquer ajuste visual futuro nos elementos de frete será feito exclusivamente na folha de estilo.
- Reuso de classes comuns (como `.egen-btn-secondary` e `.egen-product-buy`) em outras seções do site.
