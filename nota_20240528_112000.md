# Refatoração: Correção de Prefixos CSS em Componentes Estruturais

**Implementação**: Averiguação de classes CSS legadas nos templates base e atualização das classes estruturais `telhado` (para `egen-telhado` no `header.twig`) e `dropdown-menu-recursive` (para `egen-dropdown-menu-recursive` no `department-menu.twig`).

**Motivo**: Devido à adoção da arquitetura Atomic Design, seletores específicos da interface foram encapsulados em seus devidos átomos e moléculas. Havia, no entanto, tags remanescentes em organismos globais que não haviam acompanhado a recém-aplicada estratégia de isolamento CSS via prefixo (`egen-`).

**Benefício**: O ecossistema de componentes passa a refletir fielmente o CSS minificado e compilado em produção, restabelecendo backgrounds importantes (como o fundo texturizado do header) e o comportamento e layout correto do dropdown de navegação departamental, evitando falhas visuais.
