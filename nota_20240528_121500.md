# Refatoração: Encapsulamento, Performance e Sincronização CSS do JS (app.js)

**Implementação**: O script global `app.js` foi encapsulado em uma IIFE (Immediately Invoked Function Expression) sob o modo `'use strict'`. Os seletores do DOM foram atualizados para consumirem a nova arquitetura Scoped CSS do projeto (`.egen-telhado`, `.egen-dropdown-menu-recursive`, etc.). Além disso, foram implementadas melhorias de performance como Event Delegation no menu e `requestAnimationFrame` na renderização do cabeçalho fixo (sticky).

**Motivo**: A execução de variáveis e eventos soltos no escopo raiz do `window` em JavaScript gera alto risco de colisão e quebras imprevistas quando novos pacotes e bibliotecas são instalados. Além disso, listeners de scroll bloqueantes são um dos maiores causadores de baixa performance e lentidão de rolagem em dispositivos móveis, e a amarração em massa de Event Listeners dentro de laços de repetição (`forEach`) compromete a gestão de memória.

**Benefício**: Evitamos conflitos de colisão com outros scripts. A utilização do `requestAnimationFrame` e a flag `{ passive: true }` aliviam a Thread Principal do navegador, oferecendo uma experiência de rolagem de tela e animação a consistentes 60FPS. A troca para Event Delegation na árvore recursiva de categorias diminui o uso de memória no client-side. Tudo isso sincronizado corretamente com as classes base blindadas (`egen-`).
