# Refatoração: Interceptação AJAX no Formulário de Login

**Implementação**: Adição de um event listener global em `app.js` usando *Event Delegation* para interceptar o evento `submit` de formulários identificados com a classe `.egen-login-form`. A requisição foi migrada para o uso assíncrono via `fetch` API, com lógica capaz de interceptar falhas HTTP (4xx e 5xx) e extrair a chave de erro do payload JSON em respostas do servidor, conectando-a diretamente ao utilitário `window.showNotification`.

**Motivo**: A validação de login tradicional causava o recarregamento total da tela. Em casos de erro, além do custo do novo *Full Page Load*, o preenchimento era perdido ou exigia renderização de marcadores condicionais no PHP (ex: `if error`). A manipulação Client-Side resolve essa deficiência.

**Benefício**: Evita perdas de contexto visual do usuário. Se as credenciais estiverem incorretas, o formulário simplesmente não recarrega, e o *Toast* (notificação flutuante de cor vermelha configurada em `new-stylesheet.css`) informa o motivo exato rapidamente, acelerando a taxa de conversão e a percepção de performance da aplicação.

## Questão
Gostaria de ver como interceptar os formulários de Login (via AJAX) para aproveitar o `window.showNotification` em caso de erro.

## Resposta Completa do Assistente
Excelente passo para melhorar a Experiência do Usuário (UX)! Lidar com erros de autenticação sem forçar o recarregamento da página é um dos maiores diferenciais de uma loja com aspecto de Single Page Application (SPA).

A lógica será quase idêntica à que utilizamos para o carrinho de compras: vamos capturar o evento de `submit`, impedir o redirecionamento com `e.preventDefault()`, enviar as credenciais via `fetch` e, dependendo do status HTTP da resposta (como um erro 400 Bad Request ou 401 Unauthorized), acionar o nosso balão vermelho (`danger`).

Para que isso funcione universalmente, adotaremos a classe **`.egen-login-form`**. Certifique-se de que a tag `<form>` no seu arquivo Twig de login possua essa classe (ex: `<form action="/login" method="post" class="egen-login-form">`).
