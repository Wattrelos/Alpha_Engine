Para dar permissão de execução ao script, use o comando chmod +x no terminal:
```bash
chmod +x scripts/check_requirements.sh
```
Depois de executar esse comando, você poderá rodar o script diretamente com:
```bash
./scripts/check_requirements.sh
```
Se o comando falhar por falta de privilégios ou se você precisar rodar o script como administrador
```bash
sudo ./scripts/check_requirements.sh
```
