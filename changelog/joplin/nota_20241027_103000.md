# Nova Implementação: Atalho para Injeção de Data/Hora no VSCodium

**Implementação**: Configuração de um atalho de teclado personalizado no arquivo global `keybindings.json` do VSCodium, utilizando o comando interno `editor.action.insertSnippet` aliado às variáveis de ambiente dinâmicas do editor (`${CURRENT_YEAR}`, etc.).

**Motivo**: Contornar a limitação de contexto temporal das IAs. Ao invés de digitar datas manualmente nos prompts diários, o atalho permite injetar o carimbo de data e hora instantaneamente, no formato YYYYMMDD_HHMMSS.

**Benefício**: Otimização profunda do fluxo de trabalho diário. Diminui o atrito ao escrever comandos de criação de notas e scripts, previne erros de digitação de datas manuais e garante que as notas técnicas subsequentes da Alpha Engine sigam o padrão exato de nomenclatura de forma padronizada.

## Questão
Gostei da ideia. Como faço para criar um atalho no VSCodium que injete automaticamente a data e a hora atual toda vez que eu for te mandar um prompt?

## Resposta Completa do Assistente
Excelente ideia! Para fazer isso de forma totalmente nativa no VSCodium, sem precisar instalar extensões adicionais, nós podemos configurar um atalho de teclado personalizado que aciona o motor interno de *Snippets* (trechos de código) do editor.

Siga este passo a passo:
1. No seu VSCodium, abra a Paleta de Comandos pressionando `Ctrl + Shift + P`.
2. Digite **Preferências: Abrir Atalhos de Teclado (JSON)** e pressione Enter.
3. Adicione o seguinte bloco no `keybindings.json`:
`{"key": "ctrl+shift+alt+d", "command": "editor.action.insertSnippet", "args": {"snippet": "${CURRENT_YEAR}${CURRENT_MONTH}${CURRENT_DATE}_${CURRENT_HOUR}${CURRENT_MINUTE}${CURRENT_SECOND}"}}`
4. Salve o arquivo.

Sempre que você for me escrever um prompt, basta pressionar `Ctrl + Shift + Alt + D`. O VSCodium vai imprimir na mesma hora a data atualizada onde seu cursor estiver!
