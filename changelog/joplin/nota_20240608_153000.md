# Correção de Bug: Trativa de Identificador Dinâmico para Idiomas

**Implementação**
Foi adicionada uma lógica de verificação e fallback no arquivo `language.php` (evento de inicialização de idioma) para extrair o ID do idioma de forma segura e resiliente. O sistema detecta se o repositório devolveu um objeto (`Entity` usando `getId()`), um array do Alpha Engine (chave `id`) ou o formato legado do OpenCart (chave `language_id`).

**Motivo**
Com a implementação do Alpha Engine e dos conversores, as chaves primárias estão sendo devolvidas padronizadas como `id`. O código original buscava estritamente por `['language_id']`, o que disparava um `Warning: Undefined array key "language_id"` no processo de inicialização e não guardava o ID no Registry de forma correta.

**Benefício**
Garante total estabilidade do Boot de catálogo independentemente de qual Repositório/Mapper lidou com o retorno, limpa os warnings do log e mantém o estado global (`config_language_id`) íntegro para todos os demais módulos da aplicação.
