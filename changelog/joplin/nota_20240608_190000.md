# Correção de Bug: Restauração de Namespace dos Mappers e Limpeza de Imports

**Implementação**
A importação das classes `CategoryMapper` e `InformationMapper` no `SitemapRepository.php` foi restaurada para o seu sub-namespace verdadeiro (`Alpha\Mappers\EntityMappers\...`). Adicionalmente, foram limpos os `use statements` órfãos (*dead code*) no `MapperFactory.php` e uma importação circular redundante no `CategoryMapper.php`.

**Motivo**
Na refatoração anterior, houve uma tentativa de encurtar o namespace dos mappers que não correspondia com a estrutura física de pastas (`core/Mappers/EntityMappers`). Isso quebrou o padrão PSR-4, fazendo com que a constante mágica `::class` enviasse uma string errada para o `MapperFactory` tentar instanciar, originando o `Fatal Error: Class not found`.

**Benefício**
Alinhamento estrito com a PSR-4 e o autoloader do Composer. O sistema passa a localizar os mapeadores do banco de dados perfeitamente de volta, restabelecendo o fluxo do Sitemap e deixando a fábrica de mappers limpa de dependências não utilizadas.
