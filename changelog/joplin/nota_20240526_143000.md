# Refatoração: Arquivamento de Models Legados (Account)

**Implementação**: Execução de rotina no terminal para varrer o diretório `catalog/model/account/` e renomear todos os arquivos físicos de model legado (de `.php` para `.old`), inativando-os estruturalmente da base de código do sistema.

**Motivo**: Com a conclusão de 100% da refatoração dos controladores de conta (`catalog/controller/account/*.php`), todas as antigas dependências de banco de dados (`$this->load->model()`) foram substituídas pela injeção nativa de Repositórios e Entidades da Alpha Engine. Como consequência, as antigas Models de Account tornaram-se "código morto" (sem referências ativas).

**Benefício**: Limpeza estrutural profunda da base de código. Essa ação garante que a IDE (VSCodium) pare de indexar esses arquivos nas buscas de métodos, evita o uso acidental de classes depreciadas por desenvolvedores no futuro, e preserva o histórico lógico de forma segura para consultas em modo "read-only".
