# Refatoração: Padronização Alpha Engine no Módulo Admin de Total (Coupon)

**Implementação**: Refatoração do controlador do módulo de totais de Cupom localizado no painel administrativo em `extension/opencart/admin/controller/total/coupon.php`. A classe base foi migrada de `\Opencart\System\Engine\Controller` para `Alpha\Controller\BaseController`. Removeu-se as injeções repetitivas de layout do painel (`header`, `column_left`, `footer`) em favor do método encapsulado `$this->render()`. A devolução das configurações salvas no método `save()` via AJAX foi modernizada para usar `$this->jsonResponse()`.

**Motivo**: Como a extensão operava na arquitetura antiga, ela possuía código boilerplate propenso a falhas de envelopamento visual e ausência de tipagem na resposta JSON (via headers manuais). Padronizá-la garante coesão em 100% dos painéis de módulos e previne telas brancas durante a navegação interna de configurações.

**Benefício**: O código foi enxugado, a segurança nas respostas POST foi restabelecida com envelopamento protegido pela Engine, e eliminamos de vez as rotinas legadas de layout do OpenCart neste submódulo.
