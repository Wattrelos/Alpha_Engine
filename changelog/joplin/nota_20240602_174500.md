# Refatoração: Correção de Strict Mode na API de Cupons

**Implementação**: Auditoria no controlador de API de cupons (`extension/opencart/catalog/controller/api/coupon.php`). Confirmou-se que o arquivo já invoca os Repositórios de Domínio (`CartRepository` e `CouponRepository`) de forma nativa e livre do uso de models legadas. Aplicou-se também um patch de correção para prevenir um erro `Undefined array key "call"`, envelopando a checagem do método GET com `isset()`.

**Motivo**: No PHP 8+, acessar uma chave não declarada em arrays de requisição (`$this->request->get['call']`) dispara um erro de tipo ou aviso que interrompe a execução da aplicação e quebra a devolução do cabeçalho JSON da API.

**Benefício**: Evita falhas silenciosas na avaliação de cupons no checkout e confirma a completa aderência da rota de API de Cupons à arquitetura estrita do PHP 8+ e da Alpha Engine.
