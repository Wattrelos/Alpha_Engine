# Refatoração: Migração das Transações para a Alpha Engine

**Implementação**: Refatoração do `CustomerTransactionRepository` implementando a `BaseRepositoryInterface` e transferindo todos os métodos financeiros (adição, deleção e listagem/saldo) do modelo legado `account/transaction.php`. O mapeamento foi adicionado ao `AlphaContainer`.

**Motivo**: O controlador de transações já estava engatilhado para consumir o repositório central (`getTransactions`), porém o repositório estava incompleto e não cobria as pontes legadas necessárias, impossibilitando a desativação nativa do modelo do OpenCart.

**Benefício**: Desativação de mais um modelo legado e alinhamento do componente à arquitetura Alpha. A delegação de queries financeiras ao repositório permite isolar as lógicas de negócio do SQL puro, servindo diretamente os DTOs para renderização (`toArray()`) e garantindo uma melhor interface com o motor financeiro de Loja.
