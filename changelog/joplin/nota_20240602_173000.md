# Refatoração: Esvaziamento Progressivo do Model de Cupons

**Implementação**: Aplicação do padrão de "Legacy Bridge" (Esvaziamento Progressivo) no arquivo legado `/catalog/model/marketing/coupon.php`. Toda a lógica complexa interna e queries SQL foram apagadas. Os métodos da classe foram sobrescritos para atuar como *Proxies* que resgatam e delegam as requisições puramente para a instância centralizada `$repositoryFactory->get(CouponRepository::class)`.

**Motivo**: Como dita a filosofia da Alpha Engine, a validação de regras de domínio de Cupons (uso de histórico, vinculação de conta, limite de itens e mínimo do carrinho) foi extraída e consolidada no `CouponRepository`. Manter esse código macarrônico dentro do model legado criaria uma duplicação perigosa das regras de negócio financeiras, tornando a manutenção futura instável.

**Benefício**: Desacoplamento imediato das lógicas legadas. Qualquer módulo de terceiro, componente de checkout nativo ou módulo de frete que continuar carregando o model via `$this->load->model('marketing/coupon')` continuará funcionando normalmente, porém agora estará protegido por baixo dos panos (under the hood) pela robustez e cache do Repositório de Cupons da Engine Alpha. Isso também nos deixa a um passo de arquivar este componente com o `.old`.
