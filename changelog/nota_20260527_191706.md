# [Reestruturação Semântica Completa do `core/`]

**Implementação:** Auditoria e reestruturação do diretório `core/` da Alpha Engine, corrigindo posicionamento de arquivos, namespaces PHP inválidos e duplicatas que impediam o autoloader PSR-4 de reconhecer as classes corretamente.

**Motivo:** O comando `composer dump-autoload` reportava 9 avisos de classes "Skipping" (sendo ignoradas), o que poderia causar erros `Class not found` em runtime. As causas eram: arquivos em pastas divergentes do namespace declarado, múltiplas classes em um único arquivo (violação PSR-4), namespace declarado após `<?php` (sintaxe inválida) e arquivos orphans com namespace errado.

**Benefício:** O autoloader agora reconhece 1441 classes com zero avisos PSR-4. A estrutura de pastas reflete com precisão a arquitetura de camadas (Auth, Controller, Mappers, Model, Services, Support, View), facilitando navegação, manutenção e onboarding.

---

## Questão

Poderia sugerir a estrutura semanticamente correta e ajustar o "mapa"? Pode sugerir mover arquivo e pastas, caso necessário, para atender o padrão de boas práticas.

### Remoções

| Arquivo | Motivo |
|---|---|
| `core/Auth/AuthController.php` | Orphan com namespace errado; substituído por LoginController/LogoutController |
| `core/Model/DataAccessObject/LazyCollection.php` | Duplicata de `core/Support/LazyCollection.php` |
| `core/Support/Cache/OrderObserverInterface.php` | Duplicata de `core/Mappers/Observers/` |
| `core/Model/Domain/Attributes/Attributes.php` | Múltiplas classes num único arquivo (violação PSR-4) |
| `core/View` (arquivo) | Arquivo vazio de 0 bytes ocupando o lugar da pasta `View/` |
| `core/System/` (pasta) | Esvaziada após mover ViewRenderer |
| `core/Controller/EntityControllers/` (pasta) | Removida após movimentação do HomeController pelo usuário |

### Separação PSR-4 (1 classe por arquivo)

`Attributes.php` continha 4 classes PHP — dividido em:
- `HasOne.php`
- `OneToMany.php`
- `ManyToMany.php`
- `ManyToOne.php`

### Correções de Namespace/Sintaxe

| Arquivo | Problema | Correção |
|---|---|---|
| `View/ViewRenderer.php` | `Alpha\System` | → `Alpha\View` |
| `Controller/BaseController.php` | `use Alpha\System\ViewRenderer` | → `use Alpha\View\ViewRenderer` |
| `ManufacturerRepository.php` | `new \Alpha\System\ViewRenderer` | → `new \Alpha\View\ViewRenderer` |
| `Controller/Auth/LoginController.php` | `Alpha\Controllers\Auth` (plural) | → `Alpha\Controller\Auth` |
| `Controller/Auth/LogoutController.php` | `Alpha\Controllers\Auth` (plural) | → `Alpha\Controller\Auth` |
| `Support/RequestHelper.php` | `namespace` antes de `<?php` (sintaxe inválida) | Ordem corrigida |
