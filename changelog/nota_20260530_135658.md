# Configuração Explícita de Tipagem Nativa no PDO (ConnectionDB.php)

**Implementação**:
- Adição da configuração explícita `PDO::ATTR_STRINGIFY_FETCHES => false` no construtor da classe [ConnectionDB.php](file:///var/www/html/agsonhos/core/Model/DataAccessObject/ConnectionDB.php#L35-L42).
- Essa diretriz atua de forma combinada com `PDO::ATTR_EMULATE_PREPARES => false` para garantir que o driver de banco de dados (especialmente o mysqlnd) retorne os valores numéricos como tipos nativos do PHP (`int` e `float`) na leitura dos resultados, em vez de convertê-los em strings.

**Motivo**:
- Com a migração de chaves primárias e estrangeiras do banco de dados de `INT(11)` para `BIGINT`, é fundamental garantir consistência absoluta na representação dos dados numéricos. A ativação explícita de `PDO::ATTR_STRINGIFY_FETCHES => false` blinda o sistema contra qualquer conversão desnecessária para string por parte do PDO, mantendo chaves e IDs trafegando diretamente como inteiros nativos na aplicação.

**Benefício**:
- **Desempenho Otimizado**: Elimina o overhead de processamento de string e consumo de memória RAM decorrentes da conversão de tipos pelo PDO.
- **Segurança de Tipos**: Garante que o PHP e as Entidades recebam inteiros nativos diretamente do driver, preservando a assinatura rigorosa de tipos definida no core da Alpha Engine.
- **Portabilidade**: Assegura o mesmo comportamento previsível de leitura nativa de tipos numéricos independentemente de configurações específicas de `php.ini` do servidor de hospedagem.
