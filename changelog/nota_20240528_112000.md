# Refatoração: Saneamento da Página de Lista de Desejos (Wishlist)

**Implementação**
- Criação do controlador dedicado `WishlistAction.php` sob o namespace `Alpha\Controller\Actions\Account`.
- Remoção de chamadas diretas a banco de dados (ex: `$this->db->query(...)`) e lógica de manipulação de imagens, delegando a responsabilidade de consulta integralmente ao `WishlistRepository`.
- Renderização da página transferida para o `Twig\Environment`, injetando os dados limpos (DTOs) na view `pages/account/wishlist.twig`.

**Motivo**
- O controlador antigo de wishlist do OpenCart sofria da síndrome de *Fat Controller*, misturando responsabilidades de formatação de exibição, queries SQL e gerenciamento de HTTP.
- Era necessário unificar as páginas do Painel do Cliente ao padrão da **Alpha Engine** (*Skinny Controllers*, Injeção de Dependências e *Domain-Driven Design*).

**Benefício**
- O acoplamento entre a camada visual e o banco de dados foi completamente rompido.
- A página agora é inteiramente à prova de vazamentos (a proteção é garantida pelo Middleware de Sessão nas rotas e o repositório amarra a consulta automaticamente à sessão do usuário autenticado).
