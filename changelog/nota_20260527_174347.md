# [Instalação de Dependências PSR e Slim Framework]

**Implementação:** Adição dos pacotes `psr/http-message`, `psr/http-server-middleware`, `slim/psr7` e `slim/slim` ao `composer.json` via `composer require`. Os pacotes foram baixados e o autoloader otimizado foi regerado.

**Motivo:** O arquivo `core/Auth/Middleware/SignatureMiddleware.php` utilizava os tipos `Psr\Http\Message\ServerRequestInterface` e `Psr\Http\Server\RequestHandlerInterface` (linhas 5–6) e a classe `Slim\Psr7\Response` (linha 7), mas nenhum desses pacotes estava declarado no `composer.json` nem presente no `vendor/`. Isso causava o erro `Undefined type` reportado pelo IDE e potencial `Fatal error: Class not found` em runtime.

**Benefício:** O `SignatureMiddleware` agora tem todas as suas dependências de tipo satisfeitas, eliminando o erro do IDE e garantindo que o middleware funcione corretamente em runtime. O `index_new.php` também passa a ter o `Slim\Factory\AppFactory` disponível, tornando o bootstrap do roteador funcional.

---

## Questão

Explain what this problem is and help me fix it: Undefined type 'Psr\Http\Message\ServerRequestInterface'. @[/var/www/html/agsonhos/core/Auth/Middleware/SignatureMiddleware.php:L25]

## Resposta Completa do Assistente

### Diagnóstico

O erro ocorre porque o `SignatureMiddleware.php` declara as interfaces PSR como type hints:

```php
use Psr\Http\Message\ServerRequestInterface as Request;   // L5
use Psr\Http\Server\RequestHandlerInterface as Handler;   // L6
use Slim\Psr7\Response;                                   // L7
```

Porém o `composer.json` continha apenas `twig/twig` como dependência, e o diretório `vendor/psr/` não existia. O PHP e o IDE não conseguem resolver esses tipos porque os pacotes que os definem nunca foram instalados.

### Solução Aplicada

```bash
composer require psr/http-message psr/http-server-middleware slim/psr7 slim/slim
```

Pacotes instalados:
- `psr/http-message` (v2.0) — Define `ServerRequestInterface`, `ResponseInterface`, etc.
- `psr/http-server-middleware` (v1.0.2) — Define `RequestHandlerInterface`
- `psr/http-server-handler` (v1.0.2) — Dependência transitiva
- `slim/psr7` (v1.8.0) — Implementação concreta de `Slim\Psr7\Response`
- `slim/slim` — Framework principal com `Slim\Factory\AppFactory`

### Avisos Secundários Identificados (PSR-4)

O autoloader detectou classes com namespace divergente do caminho físico:
- `Alpha\Session\AlphaSessionHandler` em `core/Mappers/` (deveria ser `core/Session/`)
- `Alpha\Controller\EntityController\HomeController` em `core/Controller/EntityControllers/`
- `RequestHelper` sem namespace em `core/Support/`

Essas classes são ignoradas no autoload otimizado e podem causar erros `Class not found` quando invocadas.
