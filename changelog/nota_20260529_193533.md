# Migração do Rodapé de Bootstrap para eigen- (CSS Grid Nativo)

**Implementação**

- **`footer.twig`**: Substituídas todas as classes Bootstrap (`container`, `row`, `col-12`, `col-lg-3`, `col-md`, `col-sm-6`, `mb-4`, `mb-lg-0`, `pe-lg-4`, `text-center`, `text-md-start`, `text-md-end`, `align-items-center`, `mb-0`, `me-2`, `mx-1`, `fa-2x` com `vertical-align` inline) por hierarquia `egen-` semântica:
  - `<footer class="ag-footer">` — preservado
  - `<div class="egen-footer__container">` — container centralizado `max-width: 1320px`
  - `<div class="egen-footer__grid">` — CSS Grid: `1.5fr repeat(4, 1fr)` (coluna da marca maior)
  - `<div class="egen-footer__brand-col">` — coluna da marca (logo + descrição + redes)
  - `<img class="egen-footer__logo">` / `<h3 class="egen-footer__brand-name">` — logo ou nome
  - Inlines removidos: `style="max-height: 50px"`, `style="vertical-align: middle"`, etc.
  - `<div class="ag-footer-bottom">` com `<div class="egen-footer__bottom-row">` — flex row copyright/pagamentos
  - `<p class="ag-footer-bottom__copy">` — copyright sem `margin-bottom`
  - `<span class="payment-methods__label">` — rótulo de texto

- **`footer-column.twig`**: Substituídas `col-12 col-sm-6 col-md`, `mb-4 mb-md-0`, `list-unstyled`, `text-uppercase`, `font-weight-bold`, `text-decoration-none` por:
  - `<div class="egen-footer__col">` — flex column com gap
  - `<h5 class="footer-column__title">` — estilo via CSS (uppercase, decorador `::after`)
  - `<ul class="footer-column__list">` / `<li class="footer-column__item">` / `<a class="footer-column__link">`

- **`personalizada.css`**: Bloco do rodapé completamente reescrito:
  - `.egen-footer__grid`: `display: grid` com `grid-template-columns: 1.5fr repeat(4, 1fr)` — distribui as colunas proporcionalmente sem `col-*`
  - `.footer-column__title::after`: decorador laranja nativo (sem `h5.` de especificidade Bootstrap)
  - `.payment-methods`: `display: flex; gap: 0.5rem` — substitui `mx-1` e `me-2`
  - Responsividade em 2 breakpoints: `≤ 1199px` (2 colunas, marca em linha cheia) e `≤ 639px` (coluna única, bottom-bar empilhado)
  - Removido o seletor frágil `.col-12:hover h5.footer-column__title::after`

**Motivo**

Após a remoção do Bootstrap, o `<div class="row">` perdeu `display: flex` e os `col-*` perderam seu comportamento de colunas flexíveis, fazendo todos os blocos empilharem verticalmente em largura 100%. O `footer-column.twig` usava `col-sm-6 col-md` para distribuir colunas em grid — comportamento completamente inexistente sem o Bootstrap.

**Benefício**

- CSS Grid nativo: layout declarativo, legível e sem dependência de classes utilitárias
- Breakpoints explícitos e semânticos (`≤ 1199px`, `≤ 639px`) vs. breakpoints opacos do Bootstrap (`sm`, `md`, `lg`)
- Coluna da marca com proporção `1.5fr` vs. `1fr` — mais espaço para logo e descrição sem lógica de `col-lg-3`
- Sem `!important` em nenhuma regra do rodapé
- `focus-visible` nos links para acessibilidade por teclado

## Resposta Completa do Assistente

Migração completa do rodapé em 3 arquivos:

**`footer.twig`** — HTML limpo com `egen-`:
- `egen-footer__container` → centralizado `max-width: 1320px`
- `egen-footer__grid` → CSS Grid `1.5fr repeat(4, 1fr)` (5 colunas)
- `egen-footer__brand-col` → logo + descrição + redes sociais
- `egen-footer__bottom-row` → flex row copyright ↔ pagamentos

**`footer-column.twig`** — molecule limpa:
- `egen-footer__col` → flex column
- `footer-column__list` / `footer-column__item` / `footer-column__link`

**`personalizada.css`** — bloco do rodapé reescrito:
- CSS Grid nativo substitui `row + col-*`
- 2 breakpoints responsivos: `≤ 1199px` (2 col) e `≤ 639px` (1 col)
- Decorador `::after` no título agora ligado a `.egen-footer__col:hover` (não mais ao frágil `.col-12:hover`)
