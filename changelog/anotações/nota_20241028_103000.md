# Refatoração: Correção de Vazamento de Persistência no Painel do Cliente

**Implementação**: Substituição de `findOneBy(['customer_id' => $this->customer->getId()])` pelo método nativo `find($this->customer->getId())` ao utilizar o `CustomerAffiliateRepository` dentro de `catalog/controller/account/account.php`.

**Motivo**: A chamada anterior vazava a estrutura do banco de dados (o nome da coluna `customer_id`) para a camada de visualização/controle. Como a Primary Key conceitual do afiliado é o próprio ID do cliente, a busca direta através do `find()` atende perfeitamente ao requisito de negócio.

**Benefício**:
1. Mantém a pureza arquitetural do *Domain-Driven Design*, escondendo colunas SQL do Controller.
2. Melhora a performance ao delegar a busca para o método `find()`, que primeiro consulta a RAM (Identity Map ou Cache em Memória) antes de executar uma query repetida no banco de dados, caso a entidade já tenha sido hidratada na mesma requisição.
