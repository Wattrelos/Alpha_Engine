# Refatoração da Página de Detalhes do Produto (show.html.twig) e Estilização Customizada Sem Bootstrap

**Implementação**:
- Substituição completa de todas as classes utilitárias e componentes do Bootstrap no template [show.html.twig](file:///var/www/html/agsonhos/resources/views/pages/product/show.html.twig) por marcações HTML estruturadas sob a metodologia BEM e prefixadas com `egen-` (ex: `egen-product-page`, `egen-product-layout`, `egen-product-gallery`, `egen-product-price-card`, `egen-product-options`, etc.).
- Implementação de um controlador de abas nativo e otimizado em Vanilla JavaScript para alternar entre "Descrição" e "Especificações Técnicas" sem qualquer dependência de bibliotecas JS externas (como Bootstrap JS ou jQuery).
- Inclusão dos estilos CSS no arquivo [new-stylesheet.css](file:///var/www/html/agsonhos/public_html/css/custom/new-stylesheet.css) baseados nas variáveis e tokens de design customizados da **Alpha Engine** (como suporte a cores temáticas HSL, tons escuros, glassmorphism e sombras refinadas).
- Substituição do seletor de quantidade por um controle customizado com botões de incremento (+) e decremento (-) estilizados e funcionais via inline JavaScript.

**Motivo**:
- Eliminar o acoplamento do sistema com o framework CSS Bootstrap, que foi descontinuado e completamente removido do ecossistema da nova **Alpha Engine**.
- Seguir as diretrizes de design do projeto utilizando o prefixo `egen-` para isolar novos estilos e evitar conflitos com estilos legados.
- Garantir a independência de bibliotecas JS de terceiros para o funcionamento de componentes interativos (como abas e galerias), reduzindo o tempo de carregamento da página e otimizando a performance do cliente.

**Benefício**:
- **Consistência Visual**: A página do produto agora herda perfeitamente a identidade visual moderna e premium do projeto, com suporte nativo ao visual escuro e harmonia de cores.
- **Desempenho Otimizado**: Menor tempo para renderização (FCP/LCP) ao carregar estilos dedicados e leves em vez de carregar um framework CSS pesado completo.
- **Manutenibilidade**: A estrutura BEM torna o código CSS modular, limpo e extremamente fácil de manter ou modificar no futuro.
- **Autonomia da Engine**: Completa remoção do legado do OpenCart/Bootstrap da página do produto.

## Resposta Completa do Assistente
Realizei a refatoração completa da página de exibição do produto ([show.html.twig](file:///var/www/html/agsonhos/resources/views/pages/product/show.html.twig)) e dos seus respectivos estilos no arquivo ([new-stylesheet.css](file:///var/www/html/agsonhos/public_html/css/custom/new-stylesheet.css)), removendo por completo a dependência de classes e JavaScript do Bootstrap.

As seguintes modificações foram realizadas:
1. **Estrutura HTML & BEM**: O arquivo `show.html.twig` foi reestruturado de ponta a ponta com classes personalizadas que seguem o padrão BEM e são prefixadas com `egen-` (como `.egen-product-page`, `.egen-product-gallery`, `.egen-product-info`, `.egen-product-price-card` e `.egen-product-tabs-wrapper`).
2. **Estilização com Identidade do Projeto**: Foram adicionadas regras CSS modernas no fim de `new-stylesheet.css` utilizando as variáveis globais de cores e efeitos do tema customizado (com suporte ao padrão de layout flexível, responsividade nativa em telas menores, e visual escuro unificado).
3. **Vanilla JS para Abas**: A troca das abas de "Descrição" e "Especificações Técnicas" foi implementada de maneira nativa com um script JavaScript leve e simples no final da view, eliminando a dependência do Bootstrap JS.
4. **Seletor de Quantidade**: Foi criado um seletor de quantidade polido com botões inline de `+` e `-` que operam diretamente sobre o input de texto do formulário.
