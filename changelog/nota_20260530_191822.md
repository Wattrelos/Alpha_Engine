# [Correção: Call to member function getTotal() on null — cart não registrado no Registry]

**Implementação:** Duas alterações em `OrderRepository::collectDataFromContext()`:
1. Removida a linha `$cart = $this->registry->get('cart')` — `'cart'` nunca foi registrado no Registry do `index.php`.
2. Substituída `$data['total'] = $cart->getTotal()` por `$data['total'] = $cartRepository->getTotal()` — reutilizando o `CartRepository` já instanciado logo acima (linha 146), que possui o método `getTotal()` idêntico.

**Motivo:** A chave `'cart'` não existe no Registry da Alpha Engine. O `index.php` registra `'session'`, `'customer'`, `'config'`, `'currency'`, `'tax'`, `'weight'`, `'url'`, `'document'` e `'language'` — mas nunca um objeto `cart`. O `CartRepository` (Alpha Engine) absorveu integralmente todas as responsabilidades da antiga biblioteca `cart.php` do OpenCart, incluindo `getTotal()`.

**Benefício:** O método `collectDataFromContext()` agora opera exclusivamente sobre objetos da Alpha Engine (sem fallback para o registry legado), eliminando a dependência implícita de uma chave não-registrada. O `CartRepository::getTotal()` retorna `getSubTotal() + impostos`, que é exatamente o que o `OrderMapper::insert()` espera no campo `total` do pedido.

## Questão

> Call to a member function getTotal() on null — OrderRepository.php line 151

## Resposta Completa do Assistente

**Diagnóstico:** `$this->registry->get('cart')` retorna `null` porque a chave `'cart'` não está registrada em nenhum lugar do `index.php`. O `CartRepository` é a implementação Alpha Engine do carrinho e já expõe `getTotal()`.

**Alterações em `OrderRepository.php`:**

```php
// ANTES (errado — $cart = null)
$cart = $this->registry->get('cart');
// ...
$data['total'] = $cart->getTotal(); // Fatal: Call to member function on null

// DEPOIS (correto — reutiliza CartRepository já instanciado)
// $cart removido
// ...
$data['total'] = $cartRepository->getTotal(); // CartRepository::getTotal() = subTotal + taxes
```
