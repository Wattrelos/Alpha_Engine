# Migração do Layout do Header para eigen- (Logo à Esquerda, Conteúdo à Direita)

**Implementação**

- **`header.twig`**: Substituída a estrutura Bootstrap (`row align-items-center` + `col-auto` + `col` + `row` + `col text-end`) por hierarquia `egen-` semântica com Flexbox nativo:
  - `<header class="egen-header">` — wrapper com padding e transição
  - `<div class="egen-header__container">` — flex row: logo (esquerda) + conteúdo (direita); centralizado com `max-width: 1320px`
  - `<div class="egen-header__logo">` — flex shrink zero, alinha verticalmente ao centro
  - `<div class="egen-header__content">` — coluna flex vertical (`flex: 1 1 0`), ocupa espaço restante, gap entre top-row e utility-bar
  - `<div class="egen-header__top-row">` — linha superior com `justify-content: flex-end` para alinhar o top-nav à direita

- **`utility-bar.twig`**: Substituídos `row align-items-center mt-3 mb-3`, `col-12 col-md-auto`, `col-12 col-md`, `btn btn-dark btn-carrinho-custom` por:
  - `<div id="top" class="egen-utility-bar">` — flex row; `id="top"` preservado para compatibilidade com JS legado
  - `<div class="egen-utility-bar__menu">` — `flex: 0 0 auto`
  - `<div class="egen-utility-bar__search">` — `flex: 1 1 0` (expande)
  - `<div class="egen-utility-bar__cart">` — `flex: 0 0 auto`
  - `<a class="egen-btn-cart">` — estilo próprio substituindo `btn btn-dark btn-carrinho-custom`

- **`personalizada.css`**: Adicionados blocos `egen-header`, `egen-utility-bar`, `egen-btn-cart` e responsividade do header (antes do bloco de menu). Removido bloco sticky duplicado e `telhado header` duplicado da seção top-nav.

**Motivo**

O `header.twig` usava exclusivamente classes Bootstrap (`row`, `col`, `col-auto`, `align-items-center`, `text-end`) que pararam de funcionar após a remoção do framework. O resultado era o logo e o conteúdo sem qualquer layout — ambos aparecendo em bloco empilhado ou transbordando. A `utility-bar.twig` tinha o mesmo problema com `col-12 col-md-auto` e `col-12 col-md`.

**Benefício**

- Layout Flexbox nativo: logo fixo à esquerda (`flex: 0 0 auto`), conteúdo expande (`flex: 1 1 0`) — sem necessidade de framework
- `min-width: 0` na coluna de conteúdo previne overflow de texto em containers flex
- Responsividade explícita: em `< 992px` o container empilha verticalmente (logo centralizado), busca sobe para o topo da utility-bar
- `id="top"` preservado no utility-bar para compatibilidade com qualquer JS legado que o referencia

## Resposta Completa do Assistente

Migração completa do layout do header de Bootstrap para `egen-`. Três arquivos alterados:

**`header.twig`** — flex row com `egen-header__container`:
- `.egen-header__logo` → `flex: 0 0 auto`, logo fixo à esquerda
- `.egen-header__content` → `flex: 1 1 0`, ocupa todo o espaço restante
- `.egen-header__top-row` → `justify-content: flex-end`, top-nav à direita
- `utility-bar` inclusa abaixo do top-row

**`utility-bar.twig`** — flex row com `egen-utility-bar`:
- Menu: `flex: 0 0 auto` | Busca: `flex: 1 1 0` | Carrinho: `flex: 0 0 auto`
- Botão carrinho: `egen-btn-cart` (substitui `btn btn-dark btn-carrinho-custom`)

**`personalizada.css`**:
- Novo bloco `egen-header` (l. 111) com container, logo, content, top-row
- Novo bloco `egen-utility-bar` + `egen-btn-cart`
- Responsividade: mobile empilha verticalmente, busca sobe no topo
- Removido bloco sticky e `@media` duplicados da seção top-nav
