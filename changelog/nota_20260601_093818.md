# [Correção do Reconhecimento de Usuário Logado nas Views Twig]

**Implementação**
Ajustamos a consistência das chaves de expiração de sessão entre os middlewares e a camada de autenticação:
- Corrigimos o [AbstractAuthService.php](file:///var/www/html/agsonhos/core/Auth/Services/AbstractAuthService.php) para popular a chave genérica `$_SESSION['expire']` conjuntamente à chave específica de expiração do cliente (`$_SESSION['logged_user_expire']`).
- Atualizamos o [LanguageMiddleware.php](file:///var/www/html/agsonhos/core/Auth/Middleware/LanguageMiddleware.php) e o [SessionMiddleware.php](file:///var/www/html/agsonhos/core/Auth/Middleware/SessionMiddleware.php) para checarem tanto `$_SESSION['expire']` quanto `$_SESSION['logged_user_expire']` como fallback seguro.

**Motivo**
A barra de navegação superior ([top-nav.twig](file:///var/www/html/agsonhos/resources/views/components/molecules/top-nav.twig)) utiliza a variável global do Twig `logged` para alternar os menus de "Login/Registrar" e "Minha Conta/Pedidos/Sair". Essa variável era definida com base no retorno de `isUserLogged()`, que verificava apenas a expiração da chave `$_SESSION['expire']`. Como a autenticação de clientes gravava somente `logged_user_expire`, a sessão era considerada inválida e o cliente nunca aparecia como logado na interface visual.

**Benefício**
- O sistema e o layout [top-nav.twig](file:///var/www/html/agsonhos/resources/views/components/molecules/top-nav.twig) agora reconhecem perfeitamente o status ativo de login do cliente.
- Correção de bugs de acesso a rotas protegidas que dependiam de sessão local no Slim standalone.

## Questão
Vamos ajustar @[/var/www/html/agsonhos/resources/views/components/molecules/top-nav.twig] para que o sistema reconheça quando o cliente está logado.

## Resposta Completa do Assistente
O arquivo [top-nav.twig](file:///var/www/html/agsonhos/resources/views/components/molecules/top-nav.twig) já continha a lógica de controle correta baseada no bloco `{% if not logged %}`. O problema real que impedia o reconhecimento de login residia nos middlewares e no serviço de autenticação, devido a um descasamento de nomenclatura das chaves de expiração da sessão (`expire` vs `logged_user_expire`).

Para corrigir isso:
1. **Ajuste no Hashing de Sessão**: Modifiquei o `AbstractAuthService` para gravar ambas as chaves ao persistir a sessão local.
2. **Correção nos Middlewares**: Atualizei o `LanguageMiddleware` e o `SessionMiddleware` para validar a sessão checando as duas chaves (`expire` e `logged_user_expire`).
3. Com essas correções, a variável global `logged` passa a ser injetada corretamente no Twig, fazendo com que a barra superior reconheça o usuário logado e mostre as opções corretas.
