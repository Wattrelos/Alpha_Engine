# Estilização Premium do card-register e Unificação Visual dos Cards de Login

**Implementação**

- **`card-register.twig`**: Substituídas todas as classes Bootstrap (`border`, `rounded`, `p-3`, `d-flex`, `flex-column`, `h-100`, `text-end`, `mt-auto`, `btn`, `btn-primary`) por hierarquia BEM com prefixo `egen-`:
  - `<div class="egen-card-register">` — container glassmorphism com faixa animada `::before`
  - `<div class="egen-card-register__body">` — flex column com gap, padding e todo o texto
  - `<h2 class="egen-card-register__title">` — gradiente branco→laranja via `background-clip: text`
  - `<p class="egen-card-register__subtitle">` — cor laranja primária
  - `<p class="egen-card-register__desc">` — texto muted, `flex: 1` para empurrar o footer para baixo
  - `<div class="egen-card-register__footer">` — `justify-content: flex-end`, separador `border-top`
  - `<a class="egen-btn-primary">` — reutiliza o botão pílula com gradiente já existente
  - Adicionado ícone `fa-solid fa-user-plus` no botão CTA

- **`new-stylesheet.css`**:
  - `.egen-login-card`: migrado de card branco simples para glassmorphism (`backdrop-filter: blur(16px)`, `border: 1px solid rgba(252,144,3,0.2)`, `box-shadow: var(--egen-shadow-card)`) + faixa animada `::before` idêntica à do register
  - `.egen-login-title` e `.egen-login-subtitle`: cores atualizadas para `var(--egen-text-color)` e `var(--egen-text-muted)` (paleta dark)
  - Adicionado bloco completo `.egen-card-register` e seus elementos BEM
  - Comentários de seção reestruturados para agrupar logicamente "Cards de Login"

**Motivo**

O `card-register.twig` ficava lado a lado com o `form-login.twig` na página de login. Com o `form-login.twig` já usando `.egen-login-card` e o `card-register.twig` usando classes Bootstrap puras (`border rounded p-3...`), os dois componentes ficariam visualmente inconsistentes. Além disso, o `.egen-login-card` ainda tinha aparência de card branco simples, destoando do dark mode aplicado na página de cadastro.

**Benefício**

- Coerência visual: os dois cards da página de login (`card-register` + `form-login`) ficam visualmente idênticos — mesmo glassmorphism, mesma faixa animada, mesmo gradiente no título
- `flex-direction: column` + `flex: 1` no `__desc` + `margin-top: auto` no `__footer` garante que o botão sempre fique no rodapé, independente do tamanho do texto
- `accent-color` e ícone `fa-user-plus` no botão reforçam o CTA de cadastro
