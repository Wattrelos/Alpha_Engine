# Refatoração: Remoção de Dependência do Registry no CountryRepository

**Implementação**: 
Limpeza no método `toLegacyDTO()` da classe `CountryRepository`. A obtenção do idioma atual, que antes possuía uma amarra de verificação atrelada à existência do `$this->registry` legado (`$this->registry->get('config')->get('config_language_id')`), foi substituída pela propriedade mágica injetada `$this->language_id`.

**Motivo**: 
Este trecho de código defensivo foi implementado como uma ponte ("bridge") temporária para evitar erros quando a plataforma ainda mesclava as arquiteturas. Com o advento pleno do `AppContainer` (PSR-11) e do `AbstractRepository` na Alpha Engine, todas as requisições de ambiente (como idioma e loja atual) agora são tratadas em nível de framework abstrato, tornando a checagem manual do `Registry` global obsoleta e potencialmente perigosa caso o mesmo seja desativado.

**Benefício**: 
A padronização enxuga a verbosidade do DTO legados. Além disso, elimina completamente a última sujeira atrelada ao container antigo na conversão da entidade `Country`, garantindo que a internacionalização/tradução nativa do país continue funcionando perfeitamente em microserviços e chamadas API autônomas (Slim Framework).

## Resposta Completa do Assistente
Analisando os repositórios de localização (`CountryRepository.php` e `ZoneRepository.php`), encontrei um cenário misto, mas muito fácil de resolver!

O **`ZoneRepository.php` já está 100% limpo**. Ele consome o idioma atual e a camada de cache utilizando perfeitamente a abstração moderna da Alpha Engine (`$this->language_id` e `$this->cache`).

Porém, no **`CountryRepository.php`**, ainda existia uma verificação defensiva legada amarrada ao `Registry`. Dentro do método `toLegacyDTO()`, a classe tentava descobrir o ID do idioma atual fazendo a seguinte checagem:
`property_exists($this, 'registry') && $this->registry ? (int)$this->registry->get('config')->get('config_language_id') : null;`

Isso é um reflexo claro de código em transição! Como a classe herda de `AbstractRepository`, o ID do idioma atual já é resolvido nativa e automaticamente pelo contêiner moderno da Alpha Engine usando simplesmente `$this->language_id`.
