# [Correção de Contraste e Legibilidade nos Seletores do Checkout]

**Implementação**
- Adicionados estilos CSS explícitos para os elementos `option` contidos em seletores `.egen-form-input` e `.egen-form-select` no arquivo [new-stylesheet.css](file:///var/www/html/agsonhos/public_html/css/custom/new-stylesheet.css), definindo cor de fundo escura (`#1e2227`) e cor de texto clara (`#e8eaed`).
- Corrigida a propriedade `background-color` da classe `.egen-form-input` de `var(--egen-accent-color)` (que aplicava uma cor amarela contrastando negativamente com o texto claro) para `var(--egen-bg-input)` (um fundo escuro semitransparente ideal para o padrão visual glassmorphism).

**Motivo**
- Nos navegadores modernos, os elementos `<option>` de seletores `<select>` herdam a cor de texto clara do elemento pai em temas escuros, mas mantém a cor de fundo padrão clara (branca) do sistema operacional ou do navegador. Isso causava um efeito de "texto branco sobre fundo branco" nos seletores de estado e país (como `payment_zone_id` e `shipping_zone_id`), inviabilizando a leitura.
- O campo `.egen-form-input` continha uma atribuição errônea à variável de cor de destaque amarela (`var(--egen-accent-color)`), gerando problemas de leitura e quebra visual nas entradas de dados.

**Benefício**
- Restauração completa da legibilidade das opções de Estado e País durante o preenchimento do formulário de checkout.
- Interface visual mais profissional, integrada ao design glassmorphism premium da Alpha Engine, garantindo excelente contraste de cores e conformidade com as diretrizes de acessibilidade e design.

## Resposta Completa do Assistente
Olá! O problema de invisibilidade do texto (fonte branca com fundo branco) nos elementos de opções (especialmente em seletores como `payment_zone_id` e `shipping_zone_id`) ocorria devido ao comportamento padrão de renderização dos navegadores para elementos `<option>` sob temas escuros. Quando estilizamos a cor de texto de um `<select>` com cores claras (`var(--egen-text-color)`), as opções herdam essa cor clara, mas continuam utilizando o fundo branco padrão do navegador, resultando em um contraste nulo.

Para resolver este problema, realizamos as seguintes alterações:
1. **Estilização das Opções em Selects**: Adicionamos uma regra explícita no arquivo [new-stylesheet.css](file:///var/www/html/agsonhos/public_html/css/custom/new-stylesheet.css) para que todos os elementos `option` dentro de classes `.egen-form-input` ou `.egen-form-select` tenham fundo escuro (`#1e2227`) e cor de texto clara (`#e8eaed`). Isso garante legibilidade uniforme e profissional em qualquer navegador.
2. **Correção de Cor de Fundo de Input**: Corrigimos o `background-color` da classe `.egen-form-input` no arquivo de estilo de `var(--egen-accent-color)` (que usava amarelo) para `var(--egen-bg-input)`, mantendo a consistência do design glassmorphism de toda a Alpha Engine.
