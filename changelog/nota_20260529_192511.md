# Migração do top-nav de classes Bootstrap para prefixo egen-

**Implementação**

- **`top-nav.twig`**: Substituída a estrutura `<nav class="navbar ...">` + `<div class="container-fluid">` + `<ul class="nav nav-pills ...">` por HTML semântico puro usando a convenção BEM com prefixo `egen-`:
  - `<nav class="egen-top-nav">` — wrapper principal
  - `<ul class="egen-top-nav__list">` — lista de itens
  - `<li class="egen-top-nav__item">` — item simples
  - `<li class="egen-top-nav__item egen-top-nav__item--dropdown">` — item com dropdown (modificador BEM)
  - `<a class="egen-top-nav__link">` — link navegável
  - `<span class="egen-top-nav__label">` — rótulo de texto
  - `<i class="... egen-top-nav__caret">` — seta de dropdown
  - `<ul class="egen-top-nav__dropdown">` — painel do dropdown
  - `<a class="egen-top-nav__dropdown-item">` — item do dropdown
  - Adicionados atributos ARIA: `aria-haspopup`, `aria-expanded`, `role="menu"`, `role="menuitem"`, `role="none"`, `aria-hidden`

- **`personalizada.css`**: Removido o bloco inteiro de overrides Bootstrap (`.telhado .navbar`, `.telhado .nav`, `.telhado .nav-link`, `.telhado .dropdown-menu`, `.telhado .dropdown-item`, `.nav-item.dropdown`, etc.) e substituído por estilos `egen-` completamente independentes. Dropdown implementado 100% em CSS puro via `:hover` e `:focus-within` (sem JavaScript). Responsividade: em `max-width: 991px`, `.egen-top-nav__label` recebe `display: none` (só ícone visível) e o dropdown centraliza com `translateX(-50%)`.

**Motivo**

O Bootstrap foi removido do projeto por causar estouro de memória. Os estilos anteriores dependiam de classes Bootstrap (`navbar`, `nav`, `nav-link`, `dropdown-menu`, `dropdown-item`, `container-fluid`) e de sobrescritas com `!important` para combater a especificidade do framework, criando um código frágil e semanticamente inconsistente. Com a remoção do Bootstrap, esses seletores ficaram sem efeito ou em conflito com os resets do browser.

**Benefício**

- Zero dependência de framework CSS externo
- Prefixo `egen-` garante escopo de estilo sem colisão com bibliotecas futuras
- Convenção BEM torna a relação entre elementos explícita e autodocumentada
- Dropdown CSS-only com `:focus-within` garante acessibilidade por teclado sem JS adicional
- Responsividade nativa: apenas ícones em mobile, economizando espaço

## Questão

> Esqueci de de avisar que removi o Bootstrap por causa de estouro de memória e ficaram as tags. Agora estou implementando estilos personalizados e adicionando um prefixo egen- para não confundir com as classes Bootstrap.

## Resposta Completa do Assistente

Refatoração completa do `top-nav` para eliminar todas as dependências Bootstrap:

**`top-nav.twig`** — HTML vanilla com BEM + prefixo `egen-`:
- `<nav class="egen-top-nav">` → container flex horizontal
- `<ul class="egen-top-nav__list">` → lista de links
- Links: `egen-top-nav__link`, rótulos: `egen-top-nav__label`, seta: `egen-top-nav__caret`
- Dropdown: `egen-top-nav__item--dropdown` + `egen-top-nav__dropdown` + `egen-top-nav__dropdown-item`
- ARIA semântico adicionado

**`personalizada.css`** — bloco completamente reescrito:
- Removidos ~120 linhas de overrides Bootstrap com `!important`
- Adicionados ~150 linhas de estilos limpos `egen-` (sem `!important`)
- Dropdown via `:hover` + `:focus-within` (CSS puro)
- Mobile: labels ocultos, dropdown centralizado com `translateX(-50%)`
