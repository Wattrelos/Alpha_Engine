# [Redesign Premium: Página de Listagem de Categoria (show.html.twig)]

**Implementação:** Reescrita completa do template `resources/views/pages/category/show.html.twig` com UI dark mode premium, consistente com a linguagem visual das páginas de conta e pedidos da Alpha Engine.

**Novidades visuais:**
- **Hero dinâmico**: Quando a categoria tem imagem (`category.thumb`), ela é exibida como background com `opacity: 0.18` + overlay gradiente escuro — profundidade visual sem comprometer a legibilidade do texto
- **Subcategorias como chips**: Substituído o list de links por chips horizontais com ícone SVG de pasta, transições de cor no hover
- **Toolbar premium**: Selects com aparência customizada, seta SVG inline, label em uppercase, foco com borda índigo
- **Grid de produtos** com cards premium:
  - Badge "Oferta" em gradiente vermelho-laranja quando há preço especial
  - Overlay ao hover com botão "Ver produto" em glassmorphism
  - Scale sutil da imagem no hover
  - Preço especial em verde, preço antigo riscado
  - Dois botões: "Ver detalhes" (outline índigo) + botão carrinho (gradiente índigo-violeta com box-shadow)
- **Paginação**: Botões quadrados com SVG de setas duplas para primeira/última, gradiente no botão ativo
- **Empty state**: Ícone emoji + texto + borda tracejada sutil
- **Responsivo completo**: 2 colunas em mobile estreito, detalhes e text de botão ocultados em telas pequenas

**Motivo:** O template anterior usava classes `egen-*` sem definição própria na folha de estilos, com ícones Font Awesome e estrutura legada do OpenCart sem nenhum estilo visual moderno.

**Benefício:** A vitrine de produtos agora é o principal ponto de conversão do e-commerce — um visual premium e interativo aumenta a taxa de engajamento e de "add to cart".

## Questão

> Vamos aplicar esse estilo Premium em show.html.twig?

## Resposta Completa do Assistente

Reescrita completa do template com:
- Hero com imagem de categoria como background (quando disponível)
- Subcategorias como chips interativos
- Toolbar de filtros/ordenação com selects customizados
- Grid de produtos com card premium: overlay hover, badge de oferta, 2 botões de ação
- Paginação com SVG icons e botão ativo em gradiente
- 3 breakpoints responsivos (desktop → tablet → mobile estreito)
