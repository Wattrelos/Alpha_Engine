# Refatoração: Migração do Formato de Endereço para Padrão Repository e Data Mapper

**Implementação**: Criação das classes `AddressFormatMapper` e `AddressFormatRepository` da arquitetura Alpha e refatoração do modelo legado `catalog/model/localisation/address_format.php` para atuar como uma classe "Bridge".

**Motivo**: O modelo legado executava queries SQL atreladas à versão antiga da biblioteca DB (OpenCart) diretamente no banco. A refatoração move essa responsabilidade para a camada de Persistência Alpha (Data Mapper) e adiciona caching.

**Benefício**: 
1. Respeita as regras do *Domain-Driven Design* separando os métodos do banco de dados das regras de negócio.
2. Diminui acessos repetidos ao banco através da implementação do `CacheStrategyInterface` (TTL de 24h para formatos de endereço).
3. O arquivo legado agora apenas repassa as requisições para os componentes novos, assegurando compatibilidade retroativa (Legacy Bridge) sem quebrar extensões antigas, prevenindo telas de erro.
