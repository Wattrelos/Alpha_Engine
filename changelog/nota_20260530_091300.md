# Distribuição Uniforme de Elementos no Menu de Navegação Superior

## Questão
Como faço para que os elementos dentro de egen-top-nav__list (egen-top-nav__item) seja distribuídos uniformemente na horizontal? space-around?

## Resposta Completa do Assistente
Para fazer com que os elementos de `egen-top-nav__item` sejam distribuídos de forma uniforme na horizontal dentro de `egen-top-nav__list`, a melhor abordagem é utilizar **Flexbox** no container pai (`.egen-top-nav__list`). 

Como a lista por padrão pode não ocupar toda a largura horizontal disponível do container (`.egen-top-nav`), você precisará definir `width: 100%` (ou usar `flex-grow: 1`) nela, e alterar a propriedade `justify-content` de `flex-end` para a distribuição desejada (como `space-around`, `space-between` ou `space-evenly`).

Aqui está o exemplo de código CSS a ser aplicado em seu arquivo de estilos (no arquivo [personalizada.css](file:///var/www/html/agsonhos/public_html/css/custom/personalizada.css#L547-L557)):

```css
.egen-top-nav__list {
  display: flex;
  flex-direction: row;
  flex-wrap: nowrap;
  align-items: center;
  justify-content: space-around; /* Distribui os itens com espaçamento uniforme ao redor */
  width: 100%;                   /* Garante que a lista ocupe toda a largura disponível */
  list-style: none;
  margin: 0;
  padding: 0;
}
```

### Opções de Distribuição (`justify-content`):
1. **`space-around` (Recomendado se deseja margens nas extremidades):** Distribui os itens uniformemente. O espaço antes do primeiro item e depois do último item é igual a metade do espaço entre dois itens adjacentes.
2. **`space-between`:** O primeiro item fica totalmente alinhado à esquerda, o último item totalmente à direita, e o espaço restante é distribuído igualmente entre os demais.
3. **`space-evenly`:** Todos os espaços em branco (entre quaisquer dois itens, e entre as bordas e os itens das pontas) são exatamente iguais.

Se você também quiser que os próprios itens (`.egen-top-nav__item`) se expandam para preencher igualmente a largura disponível, você pode opcionalmente definir:
```css
.egen-top-nav__item {
  flex: 1 1 0;
  text-align: center; /* Centraliza o conteúdo do link dentro de cada item expandido */
}
```

---

**Implementação**: Alteração das regras CSS da classe `.egen-top-nav__list` no arquivo de estilo customizado para usar `justify-content: space-around;` (ou a variação preferida) e `width: 100%;` para permitir a distribuição ao longo do espaço disponível.

**Motivo**: Por padrão, a lista `.egen-top-nav__list` está alinhada à direita (`justify-content: flex-end`) e não ocupa 100% da largura, fazendo com que os itens fiquem agrupados no final da barra.

**Benefício**: Melhor alinhamento e aproveitamento do espaço em resoluções de tela maiores e intermediárias, melhorando a experiência visual e a acessibilidade de cliques nos links utilitários do cabeçalho.
