# [Redesign Premium: Página Minha Conta (account.twig)]

**Implementação:** Reescrita completa do template `resources/views/pages/users/accounts/account.twig` com layout de dashboard moderno consistente com o design da Alpha Engine.

**Estrutura do novo layout:**
- **Hero section**: breadcrumb + avatar circular com gradiente + título e subtítulo
- **3 seções condicionais**: "Minha Conta", "Meus Pedidos", "Newsletter" + "Afiliado" (se habilitado)
- **Card grid**: `auto-fill minmax(260px, 1fr)` — adapta automaticamente de 1 a N colunas
- **Cards interativos**: ícone SVG temático, label, hint text, seta de navegação com micro-animação
- **Cards com destaque visual**: "Histórico de pedidos" usa cor verde (`.account-card--highlight`) para prioridade visual

**Motivo:** O template anterior era uma lista plana de links sem nenhum estilo, usando classes legadas (`egen-*`) sem definição própria, visualmente inconsistente com a Alpha Engine.

**Benefício:** A página de conta agora comunica claramente as seções disponíveis com hierarquia visual, ícones contextuais e feedback imediato de hover — padrão de UX de dashboards modernos (Notion, Stripe, Linear).
