# Refatoração: Template Premium para Lista de Desejos (Wishlist)

**Implementação**
- Criação do template `resources/views/pages/account/wishlist.twig` totalmente acoplado ao Design System da Alpha Engine (BEM CSS e Glassmorphism).
- Substituição do layout antigo (tabela baseada em Bootstrap) por um layout em grid de cards responsivo (`.egen-wishlist-grid`), que adapta graciosamente a quantidade de itens ao tamanho da tela do dispositivo móvel ou desktop.
- Criação de um *Empty State* imersivo (caso o usuário não possua produtos na lista).
- Incorporação de classes utilitárias modernas e semânticas (`egen-btn-primary`, `egen-badge`, etc.).

**Motivo**
- O controlador já havia sido migrado para o padrão Alpha Engine na iteração anterior (`WishlistAction.php`), mas a renderização continuava pendente de desenvolvimento.
- O uso de tabelas HTML nativas em páginas de e-commerce degrada muito a experiência em dispositivos mobile.

**Benefício**
- Continuidade visual impecável para o usuário logado: a área do cliente mantém o fundo escuro, os detalhes translúcidos com blur e cores de destaque vibrantes, reforçando a identidade premium da loja.
- Maior flexibilidade e clareza nos botões de ação ("Mover para Carrinho" vs "Remover da Lista").

Vamos criar/refatorar o template Twig da Lista de Desejos (wishlist.twig) aplicando o design premium e BEM CSS.
