# Refatoração: Uso de Variáveis Formatadas no Template de Produto

**Implementação**: Atualização do template `show.html.twig` para renderizar as variáveis `price_formatted`, `special_formatted` e `tax_formatted` em vez das chaves puras (`price`, `special`, `tax`). O mesmo ajuste foi propagado para o loop de opções de produto (Select, Radio e Checkbox), garantindo que sobretaxas sejam exibidas com o símbolo da moeda correto.

**Motivo**: A action controladora `ShowProductAction.php` foi previamente refatorada para isolar responsabilidades, entregando preços com formatação monetária (aplicando regras de `Currency` e `Tax`) em propriedades separadas com o sufixo `_formatted`. O template precisava ser atualizado para ler essas chaves correspondentes e evitar apresentar floats desformatados ao cliente final.

**Benefício**: Evita falhas de layout com preços exibidos cruamente do banco de dados (ex: `150.0000`). Ao adotar este padrão, garante-se que os impostos embutidos e o câmbio selecionado na sessão sejam convertidos visualmente na página do produto, mantendo total consistência da interface.
