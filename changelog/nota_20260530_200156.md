# [Redesign Premium: Página do Carrinho de Compras (cart.twig)]

**Implementação:** Reescrita completa do template `resources/views/pages/cart/cart.twig` com UI dark mode premium, mantendo integralmente a lógica JavaScript de recálculo de totais (apenas atualizados os seletores de classe para corresponder ao novo markup).

**Mudanças estruturais:**
- **Tabela → Cards**: A tabela HTML foi substituída por uma lista de cards com grid `90px auto [controls]` por item, mais adaptável a mobile
- **Imagens maiores e com hover**: 90×90px com `object-fit: contain` e leve scale no hover
- **Preços inline**: Unidade × Total na mesma linha, dispensando colunas de tabela
- **Controles integrados ao card**: Input de qty, botão de atualizar e botão de remover compõem uma "ação row" no rodapé direito de cada card
- **Sidebar sticky**: Resumo de totais com `position: sticky; top: 1.5rem` em desktop
- **Grand total em verde**: Linha final do totais em `#4ade80` e `font-size: 1.25rem` para hierarquia visual
- **Trust badges**: Selos "Compra segura" e "Dados protegidos" com ícone SVG verde
- **Empty state**: Emoji 🛒 + texto + botão CTA gradiente

**JS preservado:** O script de recálculo de totais foi mantido com a lógica idêntica — apenas os seletores foram atualizados de `.egen-cart-total-row` para `.cart-total-row` e de `.tr closest` para `.cart-item closest`.

**Motivo:** O template anterior usava uma tabela HTML com classes `egen-*` sem estilo próprio definido, ícones Font Awesome e layout não responsivo.

**Benefício:** O carrinho é o penúltimo passo antes da conversão. Um visual premium e fluido reduz o abandono de carrinho.
