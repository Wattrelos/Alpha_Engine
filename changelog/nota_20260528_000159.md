# [Promoção do AbstractRepository: Remoção do OpenCart\Registry]

**Implementação:** Separação do `AbstractRepository` em duas classes com papéis distintos, migração em batch dos 70 repositories legados via `sed`, e promoção do `Slim\AbstractRepository` para namespace principal.

**Motivo:** O `AbstractRepository` original usava `OpenCart\Registry` como Service Locator — um anti-pattern que acoplava todos os 70+ repositories ao bootstrap do OpenCart, tornando-os inutilizáveis em qualquer contexto PSR-4 independente (Slim, CLI, testes unitários).

**Benefício:** Nova hierarquia limpa. Qualquer novo Repository do sistema Slim herda do `AbstractRepository` PSR-4 (PDO). Repositories legados continuam funcionando via `AbstractOpenCartRepository`. A migração pode ocorrer gradualmente, um repository por vez, sem nenhuma quebra do sistema OpenCart existente.

---

## Questão

Abandonando o OpenCart. Analise a possibilidade de remover as dependências com Registry e adotar o padrão PSR-4, se livrando das dependências do Opencart e tornando os Repositories consumíveis por classes independentes.

## Resposta Completa do Assistente

### Nova Hierarquia

```
AbstractRepository (PDO, PSR-4)          ← NOVO PADRÃO
  └── Slim\CategoryRepository             ← repositórios do Slim

AbstractOpenCartRepository (Registry)    ← LEGADO (não tocar)
  ├── CategoryRepository (OC)            ← 70 repositórios OpenCart
  ├── ProductRepository (OC)
  └── ... (68 outros)
```

### Arquivos criados/modificados

| Arquivo | Ação |
|---|---|
| `AbstractOpenCartRepository.php` | Novo — cópia exata do AbstractRepository legado |
| `AbstractRepository.php` | Substituído — agora é PDO-based, sem Registry |
| 70 repositórios filhos | `extends AbstractRepository` → `extends AbstractOpenCartRepository` via sed |
| `Slim/AbstractRepository.php` | Deletado — promovido para namespace principal |
| `Slim/CategoryRepository.php` | Atualizado — importa AbstractRepository principal |

### Padrão de Migração — Como converter um Repository legado

Para migrar `BannerRepository` do OpenCart para o novo padrão:

**ANTES:**
```php
class BannerRepository extends AbstractOpenCartRepository
{
    public function getBanners(): array {
        $mapper = $this->mapperFactory->get(BannerMapper::class);
        return $mapper->findAllActive($this->language_id, $this->store_id);
    }
}
```

**DEPOIS:**
```php
use Alpha\Model\Domain\Repositories\AbstractRepository;

class BannerRepository extends AbstractRepository
{
    public function getBanners(): array {
        return $this->fetchAll("
            SELECT b.banner_id, bd.name, bi.*
            FROM {$this->prefix}banner b
            JOIN {$this->prefix}banner_description bd ON b.banner_id = bd.banner_id
            WHERE b.status = 1 AND bd.language_id = :lang
        ", [':lang' => $this->languageId]);
    }
}
```
