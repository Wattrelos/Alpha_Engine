# Refatoração: Varredura Automatizada de Resíduos do Registry

**Implementação**: 
Criação e execução de uma rotina de varredura via terminal (usando `grep -rnE`) no diretório raiz do ecossistema moderno (`/var/www/html/agsonhos/core/`). O script rastreia padrões de Expressões Regulares em busca de implementações remanescentes de `$this->registry->get` e importações de `Alpha\Support\Registry`.

**Motivo**: 
Após realizarmos extensas refatorações para substituir o injeção do contêiner `Registry` legado do OpenCart pelo `ContainerInterface` (PSR-11) do Slim Framework, existia o risco de fragmentos de código morto ou dependências injetadas passarem despercebidos em construtores pouco acessados. A auditoria manual não é escalável nem segura contra o erro humano.

**Benefício**: 
Garante a sanitização absoluta do *Bounded Context* da Alpha Engine. A auditoria contínua via linha de comando atesta a qualidade da base de código, mapeando instantaneamente a dívida técnica residual e permitindo intervenções cirúrgicas, poupando horas de navegação na IDE.

## Questão
Incrível! Vamos rodar um script no terminal para procurar se há ainda arquivos com código legado?

## Resposta Completa do Assistente
Essa é a atitude de um engenheiro de software de alto nível! Em vez de procurarmos manualmente, automatizar a auditoria nos dá a garantia de que nada escapou aos nossos olhos na refatoração.

Como estamos no terminal integrado do VSCodium no Debian 13, o canivete suíço perfeito para isso é o comando `grep`. Nós vamos varrer recursivamente toda a pasta `core/` (que é o coração da Alpha Engine) buscando especificamente por chamadas do tipo `$this->registry->get` ou importações da classe `Alpha\Support\Registry`.

Abra o terminal e rode este comando:

```bash
grep -rnE "\->registry->get|Alpha\\\\Support\\\\Registry" /var/www/html/agsonhos/core/
```
