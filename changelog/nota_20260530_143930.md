# Implementação de Carrinho de Compras Persistente em LocalStorage para Visitantes (Alpha Engine)

**Implementação**:
- Adição dos atributos `data-logged` e `data-lang` no elemento `<body>` em [base.html.twig](file:///var/www/html/agsonhos/resources/views/base.html.twig) e inclusão automática de scripts específicos em [layouts/base.html.twig](file:///var/www/html/agsonhos/resources/views/layouts/base.html.twig).
- Criação do script unificado [cart.js](file:///var/www/html/agsonhos/public_html/js/cart/cart.js) que:
  *   Gerencia um objeto `guestCart` com persistência em `localStorage` (chave `egen_cart`) para operações CRUD básicas de carrinho.
  *   Intercepta o envio de qualquer formulário de compra (onde `action` inclui `/carrinho/adicionar`) quando o cliente for um visitante anônimo.
  *   Atualiza dinamicamente o número total de itens no contador do cabeçalho.
  *   Renderiza de forma 100% dinâmica toda a estrutura do carrinho na view [cart.twig](file:///var/www/html/agsonhos/resources/views/pages/cart/cart.twig) quando acessada por um cliente anônimo.
- Criação do endpoint público POST `/api/carrinho/dados` em [index.php](file:///var/www/html/agsonhos/public_html/index.php) para ler a lista bruta de IDs de produtos e opções do visitante, calcular preços unitários, somar opcionais, processar totais e gerar strings de preços formatados com a moeda ativa utilizando a infraestrutura PHP da Alpha Engine, fornecendo um payload JSON preciso para a renderização do frontend.
- Implementação de validadores e ganchos em [checkout.js](file:///var/www/html/agsonhos/public_html/js/cart/checkout.js) para prevenção de carregamento de checkout caso o carrinho local do visitante esteja vazio.
- Correção do layout herdado de `cart.twig` para estender corretamente o template unificado do projeto.
- Criação de novos estilos de layout do botão e do badge contador de itens `.egen-cart-badge` em [new-stylesheet.css](file:///var/www/html/agsonhos/public_html/css/custom/new-stylesheet.css).

**Motivo**:
- Prover uma experiência de compra moderna onde visitantes não logados (anônimos) consigam montar seus carrinhos de compra sem requisições de escrita constantes no banco de dados e sem depender de sessões PHP legadas e gordas propensas a corrupção.
- Delegar a inteligência pesada de formatação de preços e cálculos de opções dinâmicas ao core PHP do Alpha Engine, garantindo que o JS do visitante consuma sempre valores idênticos e corretos.

**Benefício**:
- **Experiência do Usuário (UX)**: Permite que o cliente navegue e reserve produtos antes de se cadastrar na loja, reduzindo a taxa de abandono.
- **Redução de Carga no DB**: Carrinhos de visitantes não geram registros órfãos ou lixo no banco de dados.
- **Consistência de Cálculos**: Todo o cálculo de moedas, taxas, subtotal e opcionais é realizado no backend, eliminando discrepâncias de arredondamento no JavaScript.

## Questão
Necessitamos de implementar o carrinho de compras (cart) para os usuários. Vamos primeiro implementar para o visitante (usuário não logado): Cliente Anônimo (javascript): Salve o carrinho no localStorage do navegador. @/var/www/html/agsonhos/public_html/js/cart/checkout.js. Tens autonomia para aplicar mudanças que achar melhor, visando as melhores práticas, organização, e o que for necessário.

## Resposta Completa do Assistente
Implementei a estrutura completa do carrinho de compras local (via `localStorage`) para clientes visitantes (não logados):

1. **Persistência de Dados**: Criei a lógica em [cart.js](file:///var/www/html/agsonhos/public_html/js/cart/cart.js) gerenciando a gravação de produtos e opções sob a chave `egen_cart` no `localStorage`.
2. **Interceptação de Ação**: Formulários que postam no carrinho interceptam a submissão no cliente caso o corpo do HTML marque `data-logged="false"`. Os produtos e suas opções são guardados localmente com feedbacks visuais dinâmicos.
3. **Badge do Cabeçalho**: Foi adicionado o elemento de contador [utility-bar.twig](file:///var/www/html/agsonhos/resources/views/components/molecules/utility-bar.twig) estilizado com CSS dedicado, sincronizando a quantidade de itens local no carregamento.
4. **Calculadora Backend (Fim do JS Math)**: Criei a rota de API segura `/api/carrinho/dados` em [index.php](file:///var/www/html/agsonhos/public_html/index.php) que recebe a lista JSON do cliente, efetua a consulta aos produtos e suas opções no banco de dados, faz o cálculo e a conversão de moedas e devolve os dados estruturados prontos para exibição.
5. **Renderização do Carrinho**: A página [cart.twig](file:///var/www/html/agsonhos/resources/views/pages/cart/cart.twig) agora renderiza toda a sua interface de tabela, quantidades e totais de forma dinâmica via JavaScript quando consumida por visitantes anônimos.
6. **Prevenção de Abuso no Checkout**: Ajustei o script [checkout.js](file:///var/www/html/agsonhos/public_html/js/cart/checkout.js) para impedir que visitantes acessem a página de checkout caso seu carrinho local esteja vazio.
