# [Sincronização Global do Mini-Cart e Contagem de Produtos]

**Implementação**
- Adicionada a injeção e leitura do `CartRepository` no [LanguageMiddleware.php](file:///var/www/html/agsonhos/core/Auth/Middleware/LanguageMiddleware.php) para obter dinamicamente a contagem física de produtos do cliente logado, exportando a variável global `cart_count` para o Twig.
- Adicionado o elemento de badge `<span class="egen-cart-badge">` ao link do carrinho na barra superior [top-nav.twig](file:///var/www/html/agsonhos/resources/views/components/molecules/top-nav.twig) e atualizado o correspondente na [utility-bar.twig](file:///var/www/html/agsonhos/resources/views/components/molecules/utility-bar.twig) para carregar o valor inicial renderizado pelo servidor.
- Modificado o método `updateHeaderCount` no arquivo [cart.js](file:///var/www/html/agsonhos/public_html/js/cart/cart.js) de modo que, no lado do cliente (visitante), a atualização do contador de itens no cabeçalho reflita simultaneamente em todos os elementos com a classe `.egen-cart-badge`.

**Motivo**
- A contagem de produtos no mini-carrinho estava desatrelada do servidor para usuários autenticados (sendo exibida estaticamente como 0 ou sem badge no topo), enquanto os visitantes só tinham a atualização de um único ID (`#egen-cart-count`).

**Benefício**
- Experiência do usuário consistente, garantindo que o mini-carrinho e o contador de cabeçalho reflitam em tempo real e de forma precisa a quantidade de produtos adicionados, independente de o cliente estar autenticado ou navegando como visitante (anônimo).

## Questão
Vamos sincronizar o mini-cart (botão carrinho), para que mostre a quantidade de produtos, tanto quando é cliente não logado (visitante) quanto cliente logado.

## Resposta Completa do Assistente
Olá! Implementamos a sincronização global da quantidade de produtos no mini-cart (botão do carrinho) tanto para visitantes quanto para usuários logados.

Aqui estão os detalhes da solução:
1. **Servidor (Usuários Logados)**:
   - Integramos o `CartRepository` no [LanguageMiddleware.php](file:///var/www/html/agsonhos/core/Auth/Middleware/LanguageMiddleware.php), fazendo com que a contagem física de produtos seja calculada dinamicamente no backend e compartilhada com todas as views do Twig através da variável global `cart_count`.
2. **Templates (Estrutura Visual)**:
   - Adicionamos o elemento de badge dinâmico ao lado do ícone de carrinho em [top-nav.twig](file:///var/www/html/agsonhos/resources/views/components/molecules/top-nav.twig).
   - Atualizamos ambos os badges do site ([top-nav.twig](file:///var/www/html/agsonhos/resources/views/components/molecules/top-nav.twig) e [utility-bar.twig](file:///var/www/html/agsonhos/resources/views/components/molecules/utility-bar.twig)) para receber o `cart_count` inicial renderizado pelo servidor, ocultando-se (`display: none`) caso esteja vazio e mostrando-se (`display: inline-flex`) quando houver itens.
3. **Javascript (Visitantes / Tempo Real)**:
   - Ajustamos o método `updateHeaderCount` em [cart.js](file:///var/www/html/agsonhos/public_html/js/cart/cart.js) para atualizar via classe `.egen-cart-badge` todos os contadores da página simultaneamente. Assim, sempre que um visitante adicionar ou remover um item, os dois botões sincronizarão na hora.
