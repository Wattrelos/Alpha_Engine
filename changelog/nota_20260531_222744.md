# [Validação do Status do Administrador no Fluxo de Autenticação]

**Implementação**
Validação do status de atividade (`status`) dos administradores durante a tentativa de login.
A validação foi implementada no método `authenticate` de `AdminAuthService.php` usando a entidade `User`:
```php
if ($user && $user->isStatus() && password_verify($password, $user->getPassword())) {
    // Permite o login
}
```
Se o administrador estiver com `status = 0` (inativo), o método `isStatus()` retornará `false`, impedindo o login e incrementando a tentativa malsucedida no bloqueio de brute-force.

**Motivo**
Administradores demitidos, desativados ou temporariamente suspensos não devem ter permissão de acesso ao painel administrativo (backoffice), mesmo que forneçam um usuário e senha válidos.

**Benefício**
- **Segurança de Acesso:** Bloqueio instantâneo e garantido de usuários inativos no sistema.
- **Auditoria de Falhas:** Tentativas de login de usuários inativos são registradas como falhas de segurança no controle de brute-force.
