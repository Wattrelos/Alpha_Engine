# Preparação dos Controles e Rotas de Carrinho para Usuários Autenticados (Alpha Engine)

**Implementação**:
- Criação dos novos controladores de ação sob `core/Controller/Actions/Cart/`:
  *   [AddCartAction.php](file:///var/www/html/agsonhos/core/Controller/Actions/Cart/AddCartAction.php): Recebe submissões via POST para adição de produtos/opções e delega ao `CartRepository`.
  *   [EditCartAction.php](file:///var/www/html/agsonhos/core/Controller/Actions/Cart/EditCartAction.php): Recebe alterações de quantidades em lote e delega ao `CartRepository`.
  *   [RemoveCartAction.php](file:///var/www/html/agsonhos/core/Controller/Actions/Cart/RemoveCartAction.php): Exclui itens do banco por ID de carrinho (`cart_id`).
- Registro dos novos controladores e rotas de edição e remoção do carrinho no arquivo de roteamento e bootstrap [index.php](file:///var/www/html/agsonhos/public_html/index.php).
- Vinculação do controlador [ShowCartAction.php](file:///var/www/html/agsonhos/core/Controller/Actions/Cart/ShowCartAction.php) à rota `/carrinho` (substituindo o antigo `CartAction`).
- Criação do endpoint público de API `POST /api/carrinho/sincronizar` para permitir que o frontend mescle os itens acumulados no `localStorage` do visitante com o carrinho no banco de dados imediatamente após o login do usuário.

**Motivo**:
- As rotas e ações para adição, edição e remoção de itens no carrinho do banco de dados não estavam registradas no roteador Slim nativo, impedindo o funcionamento do carrinho para clientes autenticados.
- É necessário prover um canal (API) para que o carrinho temporário do visitante (anônimo) seja integrado e persistido de forma automática no perfil do cliente quando ele se logar.

**Benefício**:
- **Conformidade Operacional**: O fluxo de carrinho atende perfeitamente os links e formulários gerados pelos templates Twig.
- **Preparação para Integração**: O sistema agora possui os canais necessários para que, em conjunto com o login/cadastro, o carrinho do usuário logado funcione de forma transparente e unificada.
