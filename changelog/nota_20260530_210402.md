# [Remoção de Código Morto (Instanciação Não Utilizada de PDO em index.php)]

**Implementação:** Remoção das linhas de código 68 a 82 no arquivo bootstrap principal `public_html/index.php`, que realizavam a conexão manual com o banco de dados via PDO e guardavam na variável `$pdo`.

**Motivo:** A variável `$pdo` local não estava sendo utilizada em nenhuma parte do script, visto que a conexão com o banco de dados e a gerência de queries é resolvida internamente pelas classes de Mapeamento (Mappers) e Repositórios estruturados na Alpha Engine.

**Benefício:** Redução de código inútil e redundante no bootstrap do sistema, melhorando a manutenibilidade e evitando uma conexão de banco adicional/desnecessária caso o arquivo fosse estendido de forma incorreta.

## Questão
As linhas 68 a 82 podem ser excluídas em @[public_html/index.php] ?

## Resposta Completa do Assistente
Sim, a instanciação local da variável `$pdo` foi completamente removida de `public_html/index.php`.

### Motivo detalhado:
O ecossistema da **Alpha Engine** gerencia a comunicação com o banco de dados internamente através dos Mappers (com o `MapperFactory` e `Database`), tornando a variável `$pdo` no escopo do arquivo principal um código morto sem qualquer impacto ou uso ativo.
