# Inclusão Local do Font Awesome e Limpeza do base.html.twig

**Implementação**

- **`base.html.twig`**:
  - Adicionado `<link rel="stylesheet" href="/fonts/fontawesome/css/all.min.css">` apontando para a instalação local em `public_html/fonts/fontawesome/css/all.min.css`
  - Corrigido `<title>` duplicado: havia dois elementos `<title>` (um com `{% block title %}`, outro com `{{ title }}`); unificados em um único `<title>{% block title %}{{ title|default('AgSonhos') }}{% endblock %}</title>`
  - Removida a inclusão duplicada de `personalizada.css` (estava sendo carregada duas vezes)
  - Removidos os blocos `{% if description %}`, `{% if keywords %}`, `{% if icon %}` que estavam duplicados
  - `<base href>` movido para antes dos estilos (ordem correta no `<head>`)
  - Adicionados comentários de seção `{# ── Fontes e Ícones ── #}` e `{# ── Estilos da Alpha Engine ── #}`

- **Arquivo utilizado**: `all.min.css` (104KB) — contém todos os ícones: `fa-solid`, `fa-brands`, `fa-regular` e a declaração `@font-face` apontando para os `webfonts/` presentes na mesma pasta local

**Motivo**

As classes `fa-brands fa-facebook-f`, `fa-solid fa-house`, `fa-solid fa-cart-shopping` etc. são classes do **Font Awesome 6** (Free). Sem o arquivo CSS carregado, os `<i>` ficam invisíveis (sem glifo). O arquivo já estava disponível localmente — sem necessidade de CDN externo.

**Benefício**

- Ícones funcionando em todos os componentes: header (`top-nav`, `utility-bar`), rodapé (redes sociais, formas de pagamento), botões e links
- Carregamento local: sem requisição para CDN externo (performance e privacidade)
- `<head>` limpo: sem duplicações de `<title>`, `<meta>` e `<link>` de CSS

## Questão

> Essas tags, por exemplo: "fa-brands fa-facebook-f" me parecem ser da fonte Awesome. Se for, a fonte está na pasta public_html/fonts/fontawesome/ pode adiciona-la?

## Resposta Completa do Assistente

Confirmado — são classes do **Font Awesome 6 Free**.

Adicionado no `base.html.twig`:
```html
<link rel="stylesheet" href="/fonts/fontawesome/css/all.min.css">
```

Apontando para `/var/www/html/agsonhos/public_html/fonts/fontawesome/css/all.min.css` (104KB minificado), que inclui `fa-solid`, `fa-brands` e `fa-regular` + declarações `@font-face` para os arquivos de webfont em `../webfonts/`.

Aproveitando, corrigidos 3 bugs no `base.html.twig`:
1. `<title>` duplicado → unificado com `{% block title %}`
2. `personalizada.css` importado duas vezes → removida a duplicata
3. Blocos `{% if description/keywords/icon %}` duplicados → removida a segunda ocorrência
