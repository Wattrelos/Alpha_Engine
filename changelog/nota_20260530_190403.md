# [Correção: CartMapper::getProducts() Inexistente no OrderRepository]

**Implementação:** Substituída a chamada `$cartMapper->getProducts(...)` no `OrderRepository::collectDataFromContext()` (linha 144) pela chamada correta ao `CartRepository::getProducts()`, resolvido via `alpha_repository_factory`. Também substituído o `use` do `CartMapper` pelo `use` do `CartRepository`.

**Motivo:** O `CartMapper` é responsável apenas por SQL atômico contra a tabela `cart` (linhas brutas). Ele tem métodos como `getItems()`, `addItem()`, `removeItem()`, mas **nunca** teve um `getProducts()` — esse método de hidratação completa (JOIN com produtos, preços, descontos, opções, impostos) sempre existiu no `CartRepository`. O código original do `OrderRepository` chamava um método inexistente no lugar errado da camada.

**Benefício:** O `OrderRepository` agora obtém os produtos do carrinho com a hidratação completa da Alpha Engine (preço final com desconto/promoção, opções processadas, impostos calculados) sem duplicar nenhuma lógica já implementada no `CartRepository`. A separação de responsabilidades entre Mapper (SQL) e Repository (regras de negócio) é respeitada.

## Questão

> Arruma para mim? Call to undefined method Alpha\Mappers\EntityMappers\CartMapper::getProducts()

## Resposta Completa do Assistente

O `CartMapper` não possui nem deve possuir um método `getProducts()` — essa responsabilidade pertence ao `CartRepository`, que já implementa toda a hidratação via `getItems()` + `ProductMapper::getProductsByIds()` + resolução de descontos, opções e impostos.

**Alterações em `OrderRepository.php`:**
1. `use Alpha\Mappers\EntityMappers\CartMapper` → `use Alpha\Model\Domain\Repositories\CartRepository`
2. Bloco que criava o CartMapper e chamava `getProducts(5 args)`:
```php
// ANTES (errado)
$cartMapper = $this->mapperFactory->get(CartMapper::class);
$data['products'] = $cartMapper->getProducts(...);

// DEPOIS (correto)
$cartRepository = $this->registry->get('alpha_repository_factory')->get(CartRepository::class);
$data['products'] = $cartRepository->getProducts();
```
O `CartRepository` já lê `customer_id`, `session_id`, `store_id` e `language_id` do seu próprio contexto (injetado pelo `AbstractRepository`), portanto nenhum argumento extra é necessário.
