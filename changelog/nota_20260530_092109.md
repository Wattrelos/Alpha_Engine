# Estilização Personalizada e Modernização do Breadcrumb

## Questão
Com a exclusão do Boostrap, muitos estilos ficaram "órfam" vamos formatar breadcrumb aproveitando o estilo que nõs estamos implementando e adicionando o prefixo  "egen-" para não confundir com outras marcações.

## Resposta Completa do Assistente
Com a remoção do framework Bootstrap, reestruturamos o componente de Breadcrumb (Caminho de Navegação) utilizando a metodologia BEM e o prefixo `egen-` para alinhá-lo ao design system personalizado da Alpha Engine.

### Alterações Realizadas:

1. **Estrutura Twig ([breadcrumbs.twig](file:///var/www/html/agsonhos/resources/views/components/molecules/breadcrumbs.twig))**:
   - Atualização das classes para `egen-breadcrumb`, `egen-breadcrumb__item` e `egen-breadcrumb__link`.
   - Adicionada uma verificação condicional (`{% if loop.last %}`) para que o último item (a página atual) seja renderizado como texto estático (`<span>`) em vez de um link clicável, otimizando a usabilidade e a semântica de acessibilidade.

2. **Estilo CSS ([new-stylesheet.css](file:///var/www/html/agsonhos/public_html/css/custom/new-stylesheet.css#L585-L634))**:
   - Definição do container com efeito *glassmorphism* (`background-color`, `backdrop-filter`, `border` semitransparente e `border-radius`).
   - Inserção dinâmica do separador `/` entre os itens utilizando o pseudo-elemento `::after` (evitando separadores estáticos no HTML).
   - Estilização de hover e transições suaves nos links com as cores do tema (`--egen-primary-color`).

---

**Implementação**: Reescrita do arquivo de view Twig de breadcrumbs e inserção de regras CSS específicas em `new-stylesheet.css` contendo propriedades modernas de layout e design.

**Motivo**: A remoção do Bootstrap exigiu a criação de estilos customizados para evitar elementos sem formatação (órfãos) na tela, garantindo consistência visual.

**Benefício**: Visual moderno com glassmorphism integrado ao tema da Alpha Engine, melhor semântica HTML e independência completa de bibliotecas CSS pesadas externas.
