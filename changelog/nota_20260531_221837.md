# [Implementação de Controle de Tentativas de Login para Administradores]

**Implementação**
Recriação da tabela de banco de dados `user_login` e desenvolvimento de métodos de persistência e auditoria de tentativas de login para administradores no ecossistema da Alpha Engine. 
- Adicionamos os métodos `addLoginAttempt`, `getLoginAttempts` e `deleteLoginAttempts` no `UserMapper.php`.
- Adicionamos a delegação e o método de bloqueio `isLockedOut` no `UserRepository.php`.
- Integramos o controle de brute-force e registro de falhas/sucessos diretamente no `AdminAuthService.php`.
- Atualizamos o `LoginAction` administrativo para obter e passar o endereço IP da requisição HTTP ao autenticar.

**Motivo**
A tabela original `user_login` registrava apenas históricos genéricos pós-autenticação e carecia de colunas necessárias para gerenciar tentativas falhas de login por usuário (como `username` e `total`). Alinhar a segurança do painel administrativo com as melhores práticas exige bloquear tentativas de login repetidas (brute-force) em um período de tempo.

**Benefício**
- **Proteção contra Brute-Force:** O painel administrativo agora bloqueia tentativas consecutivas (limite de 5 tentativas por 1 hora por usuário).
- **Rastreabilidade de Segurança:** Registro do IP nas tentativas falhas de login administrativo para fins de auditoria na tabela `user_login`.

## Resposta Completa do Assistente
Concluímos a implementação do controle de tentativas de login (brute-force) para administradores:

1. **Alteração no Banco de Dados (Reexecutado com Autonomia):**
   A tabela `tbkk_user_login` foi recriada para conter a estrutura de controle de tentativas, equivalente ao `customer_login`:
   ```sql
   CREATE TABLE tbkk_user_login (
     id bigint(20) NOT NULL AUTO_INCREMENT,
     username varchar(96) NOT NULL,
     ip varchar(40) NOT NULL,
     total int(4) NOT NULL DEFAULT 1,
     date_added datetime NOT NULL,
     date_modified datetime NOT NULL,
     PRIMARY KEY (id),
     KEY username (username),
     KEY ip (ip)
   ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
   ```

2. **Desenvolvimento de Métodos de Persistência:**
   - **[UserMapper.php](file:///var/www/html/agsonhos/core/Mappers/EntityMappers/UserMapper.php):** Implementação dos métodos `addLoginAttempt` (insere a tentativa), `getLoginAttempts` (soma tentativas na última hora) e `deleteLoginAttempts` (limpa o histórico de falhas).
   - **[UserRepository.php](file:///var/www/html/agsonhos/core/Model/Domain/Repositories/UserRepository.php):** Adicionados os métodos wrapper e a verificação lógica de bloqueio `isLockedOut`.
