# Correção de Erro de Serialização JSON (Membro Falso em fwrite) no Endpoint de Estados

**Implementação**
Refatorado o endpoint de API `/api/paises/{country_id}/estados` em [index.php](file:///var/www/html/agsonhos/public_html/index.php). Em vez de passar a lista de entidades ricas de `Zone` diretamente para o `json_encode`, o array é mapeado manualmente para uma lista de estruturas associativas simples contendo apenas as chaves primárias e necessárias (`id`, `name`, `code`).

**Motivo**
A tentativa de serializar o grafo de objetos da classe `Zone` gerava um erro interno de codificação ou de referências circulares ocultas no conversor genérico (ou por problemas de codificação UTF-8 em nomes de estados), fazendo com que `json_encode()` retornasse `false`. Ao passar o valor booleano `false` para o método `$response->getBody()->write()`, a biblioteca de streams do PSR-7 tentava passá-lo para a função `fwrite()`, que exige estritamente dados do tipo `string`, provocando um erro fatal de tipo.

**Benefício**
- **Eliminação de Erros de Tipo:** Resolução definitiva do "Slim Application Error" provocado pelo argumento do tipo booleano em `fwrite()`.
- **Performance e Segurança de Payload:** Apenas as informações estritamente úteis (`id`, `name`, `code`) são enviadas na resposta HTTP, reduzindo o tamanho do tráfego JSON e evitando recursão ou loops cíclicos de entidades.
