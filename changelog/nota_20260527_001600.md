# Refatoração: Decomissionamento e Migração da Classe AddressFormat para a Alpha Engine

**Implementação**:
- **Bypass no AlphaContainer**: Mapeamos `'localisation/address_format'` no `repositoriesMap` da [AlphaContainer.php](file:///var/www/html/agsonhos/core/AlphaContainer.php) para redirecionar as chamadas interceptadas automaticamente para o `AddressFormatRepository`.
- **Compatibilidade Legada**: Implementamos o método `getAddressFormat(int $address_format_id): array` no [AddressFormatRepository.php](file:///var/www/html/agsonhos/core/Model/Domain/Repositories/AddressFormatRepository.php) para retornar o DTO em formato de array plano esperado pelas views do OpenCart.
- **Correção da Chave Primária**: Ajustamos a propriedade `$primaryKey` de `'address_format_id'` para `'id'` no [AddressFormatMapper.php](file:///var/www/html/agsonhos/core/Mappers/EntityMappers/AddressFormatMapper.php) para alinhar-se com o schema físico do banco de dados (que possui apenas a coluna `id` na tabela `tbkk_address_format`).
- **Simplificação e ORM Nativo**: Refatoramos o `AddressFormatMapper` para estender `BaseMapper` em vez de `AbstractMapper`, habilitando o mecanismo de lazy loading e hidratação automática do DAO ORM da Alpha Engine, removendo métodos duplicados de consulta SQL manual.
- **Esvaziamento do Legado**: Limpamos por completo a lógica interna da classe `AddressFormat` em [catalog/model/localisation/address_format.php](file:///var/www/html/agsonhos/catalog/model/localisation/address_format.php) deixando-a apenas como casca para evitar conflitos de carregamento caso necessário.

**Motivo**:
- A classe de mapeamento anterior (`AddressFormatMapper`) estava estendendo a classe incorreta e apontando para uma chave primária inexistente no banco de dados (`address_format_id` em vez de `id`). Além disso, não inicializava a propriedade `$dao`, causando erros fatais (`Fatal error`) na execução.
- O mapeamento centralizado no `AlphaContainer` remove a necessidade de carregamento legado `$this->load->model('localisation/address_format')` mantendo o padrão arquitetural do projeto.

**Benefício**:
- Redução de débito técnico com o esvaziamento da classe legada.
- Suporte nativo à hidratação automática via ORM (Active Record pattern) do Alpha Engine.
- Estabilidade nas queries e prevenção de White Screen of Death (WSOD) na recuperação dos formatos de endereço.
