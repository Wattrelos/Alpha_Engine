# [Desacoplamento e Criação de CalculateVisitorCartAction (index.php)]

**Implementação:** Extração da lógica procedural da API de cálculo de carrinho do visitante (`/api/carrinho/dados`) presente no arquivo principal `public_html/index.php` para um arquivo controlador especializado `Alpha\Controller\Actions\Cart\CalculateVisitorCartAction`. O novo controlador implementa a interface `ActionInterface`, recebe o `Registry` via injeção no construtor para obter dependências do banco, calcula os itens locais do visitante estruturados no payload JSON e retorna os dados de carrinho e subtotais formatados em JSON. O arquivo `index.php` agora simplesmente delega a execução da rota para o novo controlador através do `AppContainer`.

**Motivo:** Seguir o princípio de responsabilidade única (Single Responsibility Principle) e manter a arquitetura da Alpha Engine orientada a objetos e componentes, limpando o bootstrap principal da aplicação.

**Benefício:** Redução de código procedural e duplicações no index.php, maior facilidade de manutenção e teste isolado do processamento do carrinho local do visitante, além de manter o ecossistema de controllers uniforme.

## Questão

## Resposta Completa do Assistente
Sim, desacoplamos a API de cálculo de carrinho do visitante, movendo toda a sua lógica para um controlador de ação especializado e injetável.

### Ações Executadas:
1. **[CalculateVisitorCartAction.php](file:///var/www/html/agsonhos/core/Controller/Actions/Cart/CalculateVisitorCartAction.php)**:
   - Novo controller criado sob a estrutura de namespaces `Alpha\Controller\Actions\Cart`.
   - Implementa a interface `ActionInterface`.
   - Gerencia a decodificação dos itens locais do visitante, resolve preços, opções dinâmicas, imagens e subtotais usando a infraestrutura do Registry.

2. **[index.php](file:///var/www/html/agsonhos/public_html/index.php)**:
   - Removida a Closure longa e complexa da rota `/api/carrinho/dados`.
   - A rota foi simplificada para delegar diretamente a execução ao novo controller instanciado pelo `AppContainer`.
