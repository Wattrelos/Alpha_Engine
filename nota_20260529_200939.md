# Estilização Premium da Página de Cadastro com Paleta da Alpha Engine

**Implementação**

- **`new-stylesheet.css`** — Variáveis e estilos completamente reformulados:
  - `--egen-primary-color: #fc9003` (laranja Alpha Engine, substituindo `#007bff` Bootstrap)
  - `--egen-accent-color: #ffc107` (amarelo de destaque)
  - `--egen-bg-page: #0f1318` (fundo escuro da página)
  - `--egen-bg-card: rgba(30, 34, 39, 0.85)` (card glassmorphism com transparência)
  - `--egen-bg-input: rgba(255, 255, 255, 0.07)` (inputs com fundo translúcido escuro)
  - `--egen-bg-input-focus: rgba(252, 144, 3, 0.08)` (glow laranja no foco)
  - `--egen-text-color: #e8eaed` (texto claro para fundo escuro)
  - `--egen-border-color: rgba(255, 255, 255, 0.1)` (bordas sutis translúcidas)
  - `--egen-shadow-card: 0 20px 60px rgba(0, 0, 0, 0.5)` (sombra profunda no card)
  - `--egen-shadow-btn: 0 4px 15px rgba(252, 144, 3, 0.4)` (glow laranja no botão)
  - `.egen-register-page`: wrapper com `radial-gradient` de brasa laranja nos cantos
  - `.egen-register-container`: `backdrop-filter: blur(16px)` + borda laranja + `border-radius: 16px`
  - `.egen-register-container::before`: faixa animada com `@keyframes shimmer-bar` no topo do card
  - `.egen-register-title`: gradiente branco→laranja em `-webkit-text-fill-color: transparent`
  - `.egen-legend::after`: barra decorativa com gradiente laranja→amarelo
  - `.egen-form-input`: fundo translúcido + `box-shadow: 0 0 0 3px rgba(252,144,3,0.15)` no foco
  - `.egen-form-input::placeholder`: opacidade reduzida para aparência elegante
  - `.egen-btn-primary`: gradiente laranja com `border-radius: 50px` (pílula), `transform: translateY(-2px)` no hover e `box-shadow` de glow intenso
  - `.egen-form-footer`: `flex-direction: row; justify-content: space-between` (checkbox esquerda, botão direita)
  - `.text-danger`: migrado para `var(--egen-error-color): #ff6b6b` (vermelho suave para fundo escuro)
  - `.egen-invalid-feedback`: `animation: fadeInDown` para micro-animação de erro

- **`register.twig`**:
  - Adicionado `<div class="egen-register-page">` como wrapper externo para o fundo escuro
  - Segundo `<fieldset>` recebeu `class="egen-fieldset"` e `<legend class="egen-legend">` com o texto "Senha de Acesso"
  - Removido o `<div class="egen-form-input">` incorreto que envolvia os `<input>` de senha (estava aplicando estilo de input num container)
  - `error-confirm` migrado de `class="text-danger"` para `class="egen-invalid-feedback"`

**Motivo**

A página usava `--egen-primary-color: #007bff` (azul Bootstrap genérico) sem relação com a identidade visual do projeto. Os inputs eram claros/brancos sobre fundo branco — sem contraste ou personalidade. O botão era um retângulo azul simples. A página não tinha fundo próprio, deixando o branco padrão do browser.

**Benefício**

- Coerência visual: paleta `#fc9003` (laranja) em todos os elementos interativos — mesma identidade do header e footer
- Dark mode nativo: fundo `#0f1318` com `radial-gradient` de brilho laranja sutil nos cantos
- Glassmorphism: card com `backdrop-filter: blur(16px)` e borda laranja translúcida
- Micro-animações: shimmer no topo do card, fadeInDown nos erros, hover lift no botão
- Acessibilidade: `accent-color` no checkbox, `focus-visible` nos inputs, contraste adequado
