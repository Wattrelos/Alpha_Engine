# [Barra de Rolagem Interna com Lupa para a Lista de Fabricantes]

**Implementação**
- Adicionado campo de entrada de texto `.egen-filter-search-input` para busca instantânea e envolto a listagem de fabricantes no contêiner `.egen-filter-options-scrollbox` com rolagem vertical limitada (`max-height: 200px`) no arquivo [aside_filters.html.twig](file:///var/www/html/agsonhos/resources/views/components/organisms/aside_filters.html.twig).
- Criação de lógica de filtragem instantânea em JavaScript que escuta o evento `input` na caixa de pesquisa, remove acentos (normalização Unicode NFD) e oculta as marcas que não correspondem à pesquisa digitada.
- Adicionadas as regras de estilo e personalização da barra de rolagem (scrollbar com cores da marca Alpha Engine) no arquivo [new-stylesheet.css](file:///var/www/html/agsonhos/public_html/css/custom/new-stylesheet.css).

**Motivo**
Com uma base de 309 marcas/fabricantes, a exibição de todas as marcas em uma lista simples empilhada causava o efeito "Scroll Fatigue", alongando a barra lateral da página de categorias indefinidamente e prejudicando a experiência do usuário. 

**Benefício**
- **UX Premium (Frictionless):** O usuário encontra rapidamente a marca desejada digitando apenas as primeiras letras, com feedback imediato (JavaScript puro, tempo de resposta instantâneo e sem requisição ao servidor).
- **Layout Compacto:** A barra lateral mantém uma altura máxima controlada e elegante, preservando a harmonia estética do layout de navegação facetada da categoria.
- **Scrollbar Estilizado:** A barra de rolagem interna do contêiner utiliza a identidade visual e as cores do projeto.

## Questão
Em @[/var/www/html/agsonhos/resources/views/components/organisms/aside_filters.html.twig] , o filtro MANUFACTURER ficou extenso (309 fabricantes), vamos implementar barra de Rolagem Interna com Lupa (Inline Scrollbox)
Vantagem: O usuário digita "S" e o JavaScript instantaneamente oculta as marcas que não começam com S na lista.

## Resposta Completa do Assistente
Implementei a barra de rolagem interna limitada (**Inline Scrollbox**) integrada com uma caixa de pesquisa por texto (**Lupa**) para a listagem de marcas/fabricantes:
1. **Marcação HTML e JS:** Atualizei [aside_filters.html.twig](file:///var/www/html/agsonhos/resources/views/components/organisms/aside_filters.html.twig) adicionando o input de texto para busca e agrupando as checkboxes em uma `div` de rolagem. Adicionei um script leve que normaliza caracteres (removendo acentos) e filtra a lista instantaneamente conforme o usuário digita.
2. **Estilização Premium:** No arquivo [new-stylesheet.css](file:///var/www/html/agsonhos/public_html/css/custom/new-stylesheet.css), limitei a altura máxima da caixa a `200px` com `overflow-y: auto`, estilizei o campo de pesquisa com foco coerente à identidade visual e personalizei a barra de rolagem com cores e efeitos da Alpha Engine.
