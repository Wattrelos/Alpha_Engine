# [Disponibilização Global da Variável de Sessão Logged no Twig]

**Implementação**
- Adicionamos a lógica de verificação de sessão ativa no [LanguageMiddleware.php](file:///var/www/html/agsonhos/core/Auth/Middleware/LanguageMiddleware.php), que é executado globalmente em todas as rotas da aplicação.
- O middleware agora detecta se o cliente possui uma sessão ativa (seja via Redis ou via sessões PHP locais em fallback) e injeta a variável global `logged` no Twig (`$this->twig->addGlobal('logged', $isLogged)`).

**Motivo**
- A variável `logged` utilizada em componentes globais do layout como a barra de navegação superior ([top-nav.twig](file:///var/www/html/agsonhos/resources/views/components/molecules/top-nav.twig)) não estava sendo disponibilizada globalmente no Twig. Com isso, mesmo após o login bem-sucedido, o cabeçalho continuava mostrando os botões de "Registrar" e "Login" em vez de "Minha Conta" e "Sair".

**Benefício**
- Correção de exibição do estado de login na barra de navegação em todas as páginas da loja (como Home, Detalhes de Produtos e Categorias).
- Detecção automatizada de sessões ativas com suporte a fallback resiliente caso o Redis esteja inativo.

## Questão
```
Aparentemente, a variável {% if not logged %} está chegando vazia.
```

## Resposta Completa do Assistente
Corrigi a ausência da variável global `logged` no Twig. 

Como o componente da barra de navegação ([top-nav.twig](file:///var/www/html/agsonhos/resources/views/components/molecules/top-nav.twig)) é renderizado globalmente, ele precisa ter acesso à informação de se o usuário está logado ou não em qualquer rota (e não apenas nas rotas que utilizam o `SessionMiddleware` restritivo).

Para resolver isso, implementamos no [LanguageMiddleware.php](file:///var/www/html/agsonhos/core/Auth/Middleware/LanguageMiddleware.php) (que roda globalmente) um validador de sessão leve e otimizado (`isUserLogged`). Ele verifica a existência do cookie `session_id` e checa a presença do usuário logado no Redis ou na sessão PHP (fallback). Em seguida, define a global `logged` no Twig de forma dinâmica, fazendo com que o menu do topo se comporte de acordo com o estado real de autenticação do cliente.
