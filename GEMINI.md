# Diretrizes de Contexto Recorrente
- **Obrigatório:** Toda vez que iniciarmos uma tarefa ou análise, utilize a ferramenta de leitura de arquivos para examinar o conteúdo de `CHANGELOG1.md` e quaisquer arquivos `.md` presentes no diretório `/docs`.
- Use as informações desses arquivos para se situar sobre o andamento e o estágio atual do projeto.
- Atualize os arquivos adicionando informações sobre as tarefas relizadas e o andamento do projeto.
- Arquivos .old são obsoletos e não devem ser utilizado e devem ser evitados. Serve apenas para consulta, caso precise enteder a lógica do sistema legado.
- Evitar ao máximo utilizar loader.php, pois o carregamento legado do OpenCart causa alguns problemas às novas implementações.
